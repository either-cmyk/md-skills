# FBC + 밀크런 개당 물류비용 계산기

사용자가 박스당 입수량을 알려주면, FBC 보관비와 밀크런 운송비를 합산하여 상품 1개당 물류비용을 계산한다.

## 고정 파라미터

아래는 현재 고정된 기준값이다. 사용자가 별도 변경을 요청하지 않는 한 이 값을 그대로 사용한다.

## 기본 계산 (인천4 기준)

### 사전 계산된 박스당 비용

#### 88,000원/CBM 기준
- FBC/박스 = 0.0949 × 88,000 = **8,351원**
- 밀크런/박스 = **596원**
- **합계/박스 = 8,947원**

#### 98,000원/CBM 기준
- FBC/박스 = 0.0949 × 98,000 = **9,300원**
- 밀크런/박스 = **596원**
- **합계/박스 = 9,896원**

### 계산 방법

사용자가 입수량(박스당 상품 개수)을 알려주면:

```
개당 비용(88k) = 8,947 ÷ 입수량
개당 비용(98k) = 9,896 ÷ 입수량
```

개당 비용(98k) = 해당 센터 합계/박스(98k) ÷ 입수량

## 응답 형식

### 기본 응답 (인천4, 입수량만 받았을 때)

반드시 아래 표 형식으로 간결하게 응답한다. 불필요한 설명이나 계산 과정은 생략하고 결과만 보여준다.

```
| CBM 단가 | 합계/박스 | ÷ {입수량}개 | **개당 비용** |
|---|---|---|---|
| 88,000원 | 8,947원 | ÷ {입수량} | **{결과}원** |
| 98,000원 | 9,896원 | ÷ {입수량} | **{결과}원** |
```

결과값은 소수점 이하 반올림하여 정수로 표시한다.
마지막에 "다음 입수량 알려주세요!" 한 줄을 추가하여 연속 계산이 가능하도록 안내한다.

### 센터 지정 응답 (특정 센터를 언급했을 때)

기본 응답과 동일한 표 형식을 사용하되, 상단에 어떤 센터 기준인지 표시한다.

```
**{센터명} 기준:**

| CBM 단가 | 합계/박스 | ÷ {입수량}개 | **개당 비용** |
|---|---|---|---|
| 88,000원 | {해당 센터 합계/박스(88k)}원 | ÷ {입수량} | **{결과}원** |
| 98,000원 | {해당 센터 합계/박스(98k)}원 | ÷ {입수량} | **{결과}원** |
```
