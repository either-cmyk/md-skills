# 뉴트리정 재고관리 자동화

## 개요

이 스킬은 3가지 독립된 업무를 단계별로 선택 실행한다:

1. **사방넷 재고 조회 → 구글시트 AB열 입력** (보관수량 업데이트)
2. **한미양행 발주서 자동 생성** (W열 자동발주 계산기 기반)
3. **에이투지 세트포장 요청** (R열 자동번들 계산기 기반)

사용자가 "재고 업데이트해줘"라고 하면 1번만, "발주서 만들어줘"라고 하면 2번만, "전부 해줘"라고 하면 1→2→3 순서로 실행한다. 어떤 작업을 원하는지 불분명하면 물어본다.

## STEP 1: 사방넷 재고 조회 → 구글시트 AB열 입력

### 사방넷 접속 정보

| 항목 | 값 |
|------|-----|
| URL | `https://wms02.sbfulfillment.co.kr/stock/expiration-date` |
| 계정 | 뉴트리정(영양제) - 크롬에 이미 로그인됨 |
| 페이지 | **재고조회(유통기한)** ← 반드시 이 페이지 사용 (기본 페이지 X) |

### 핵심 규칙

1. **출고가능** 수량만 사용 (총재고 X, 입고대기 X)
2. **소비기한(유통기한)별로 수량을 분할** → 구글시트 AC열 소비기한과 매칭하여 각 행에 나눠 입력
3. **봄로지스 상품(AF열 "봄")**: AB열은 사용자가 수기 최신화 → R/W열 계산은 동일 취급
   - AB열 자동 스크래핑 시 사방넷에 0이면 기존 AB값 유지 (사용자 수기 입력값 덮어쓰기 방지)

### 소비기한 분할 로직

사방넷 재고조회(유통기한) 페이지에서 각 상품의 출고가능 수량은 소비기한(유통기한)별 배치로 나뉜다.
구글시트에서 각 상품은 6개 행(1개~6개 옵션)을 차지하며, **1개 옵션 행의 AB열**에 보관수량을 입력한다.

- **배치가 1개인 상품**: 해당 1개 옵션 행의 AB열에 전체 출고가능 수량 입력
- **배치가 2개인 상품**: 1차분(AC열 소비기한 일치하는 행)의 AB열에 1차 수량, 2차분은 다음 1개 옵션 행(+6행)의 AB열에 2차 수량
  - 예) 브로멜라인: AB87=1726 (28.02.02), AB88은 2개옵션이므로 → 실제로는 AB87에 1차, AC가 2차 소비기한인 행에 2차 수량
  - **중요**: 배치 분할 시 사방넷의 유통기한(YYYY-MM-DD)과 구글시트 AC열 소비기한(YY.MM.DD)의 포맷을 변환하여 매칭

### 사방넷 테이블 구조 (재고조회 유통기한 페이지)

### 실행 플로우

#### 1-1. 사방넷 재고조회(유통기한) 페이지에서 데이터 스크래핑

1. 사방넷 재고조회(유통기한) 페이지 (`/stock/expiration-date`)로 이동
2. 검색 버튼 클릭 (전체 조회)
3. JavaScript로 출고가능 수량 + 유통기한별 배치 데이터 스크래핑:

```javascript
(function(){
var table = document.querySelector('table');
var rows = table.rows;
var result = [];
var currentCode = '';
for (var r = 0; r < rows.length; r++) {
  var rowText = rows[r].textContent;
  var codeMatch = rowText.match(/(N002\d+)/);
  if (codeMatch) currentCode = codeMatch[1];
  if (rowText.includes('출고가능') && !rowText.includes('입고대기')) {
    var cells = rows[r].cells;
    if (cells[0]?.textContent?.trim() !== '출고가능') continue;
    var totalQty = cells[1]?.textContent?.trim() || '0';
    var lastCell = cells[cells.length - 1];
    var cards = lastCell.querySelectorAll('.card-expiration-date');
    var batches = [];
    cards.forEach(function(card) {
      var divs = card.querySelectorAll('div');
      var leafTexts = [];
      divs.forEach(function(d) {
        if (d.children.length === 0 && d.textContent.trim()) {
          leafTexts.push(d.textContent.trim());
        }
      });
      if (leafTexts.length >= 2) {
        batches.push(leafTexts[0] + ':' + leafTexts[1]);
      }
    });
    result.push(currentCode + '|' + totalQty + '|' + batches.join(';'));
  }
}
return result.join('\n');
})()
```

**출력 형식**: `상품코드|총출고가능|소비기한1:수량1;소비기한2:수량2`
예) `N00200003|2920|2028-02-02:1726;2028-03-08:1194`

- 행 23: 합계

### 실행 플로우

#### 2-1. 구글시트 W열 읽기

gviz로 W열(자동발주 계산기) 값을 읽어 발주 필요 상품을 파악:

```javascript
(async function(){

  var url = 'https://docs.google.com/spreadsheets/d/'+sid+'/gviz/tq?tqx=out:csv&gid=0&tq=SELECT+B,M,W+WHERE+W+is+not+null&range=A2:W200';
```

W열에 값이 있는 상품 = 발주 필요. W열의 값 = 발주 수량.

> **중요**: W열의 발주 수량은 **낱개(원료) 기준**이다. 1개 옵션 행에만 발주 수량이 표시된다.

#### 2-2. 발주서 엑셀 생성

Python openpyxl로 발주서 양식 템플릿을 열고, 발주 상품을 채운다:

```python
from openpyxl import load_workbook
from datetime import date

wb = load_workbook('발주서 양식_뉴트리정(한미양행).xlsx')

# 발주일자 업데이트
```

## 쿠팡 입고 규칙 (소비기한 관련)

- **같은 옵션 + 다른 소비기한 → 동시 입고 불가**

- **다른 옵션 + 다른 소비기한 → 동시 입고 가능**
  - ✅ 알파CD 1개 (28.03.12) + 알파CD 2개 (28.03.31) → 가능
- **따라서 선입선출이 매우 중요** → 1차 입고 물량(소비기한 빠른 배치)을 먼저 소진해야 2차 물량 입고 가능

## 주의사항

- **사방넷에서 값 변경은 하지 않는다.** 읽기만 한다.
- **구글시트 수식이 있는 셀(Q, R, W열 등)은 절대 수정하지 않는다.** AB열(보관수량)만 입력한다.
- **발주서는 생성만 하고 실제 발주는 사용자가 직접 한다.**
- **총재고가 아닌 출고가능 수량만 사용한다.** (출고작업중 수량 제외)
- **봄로지스 상품 → AB열은 사용자가 수기 최신화, R/W열 계산은 다른 상품과 동일하게 진행**
- **소비기한(유통기한)별로 수량을 분할 기입한다.** 사방넷 유통기한과 구글시트 AC열을 매칭
- **AD/AE열 발주 기입**: AE열(1차 발주)에 먼저 기입 → 2차 발주 시 AD열에 기입. 형식: `수량(날짜)` 예) `7000(3/13)`
- **X열 날짜**: 비어있는 X열의 2행에 오늘+7영업일 날짜 기입
- **S열은 기입하지 않는다.** X열만 입력
- **1개 입고 판단**: O열(15일 판매) > Q열(현재고)이면 → 해당 상품 1파렛 수량만큼 X열에 기입 (소량 파렛 상품은 2~3파렛 고려)
- 데이터 정합성을 위해 업데이트 전후 값을 비교하여 리포트한다.
