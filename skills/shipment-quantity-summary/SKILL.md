# 출고수량정리 스킬

물류 출고내역 엑셀 파일(S-QED 형식)을 분석하여 상품·옵션별 출고수량을 집계하고, 파레트 수를 계산하여 보기 좋은 정리 엑셀을 생성한다.

## 입력 파일 형식

사용자가 업로드하는 엑셀 파일의 구조는 다음과 같다:

- **Row 1**: 문서 제목 + 박스수량 정보 (예: `S-QED260407_주식회사 이더컴퍼니_출고내역 박스수량:40(40상자+0PL)`)
- **Row 2**: 헤더 행 (트레이 번호, 상자 번호, 발주번호, URL, 이미지, SKU, 품명, **라벨명**, 중문옵션, 발주수량, **출고수량**, **세트수량**, ...)
- **Row 3~**: 데이터 (각 행이 하나의 박스를 나타냄, 같은 상품이 여러 박스에 걸쳐 있을 수 있음)

핵심 열:
- **H열 (라벨명)**: `상품명, 옵션1, 옵션2` 형태. 쉼표+공백(`, `)으로 첫 번째 구분하여 상품명과 옵션을 분리
- **K열 (출고수량)**: 해당 박스의 출고 수량 (개별 단위)
- **L열 (세트수량)**: 세트 상품인 경우 세트 단위 수량. 이 값이 있으면(0이 아닌 숫자) K열 대신 L열 값을 사용

## 수량 결정 로직

이 로직이 이 스킬의 핵심이다. 쿠팡 입고 시 과착되면 바로 회송되므로 정확해야 한다.

1. 각 데이터 행에서 L열(세트수량) 값을 확인
2. **L열에 값이 있고 0이 아닌 경우** → L열 값을 적용수량으로 사용 (세트 상품)
3. **L열이 비어있거나 0인 경우** → K열(출고수량) 값을 적용수량으로 사용
4. 같은 상품+옵션 조합의 모든 행의 적용수량을 합산

이렇게 하는 이유: 세트 상품(예: 브라 3p)의 경우 K열에는 낱개 수량(90개)이, L열에는 세트 수량(30세트)이 들어간다. 쿠팡 입고는 세트 단위이므로 L열 기준이 맞다.

## 박스수량 추출

Row 1의 텍스트에서 정규식으로 박스수량 정보를 파싱한다:
```
패턴: 박스수량:(\d+)\((\d+)상자\+(\d+)PL\)
```
- 총 박스수, 상자 수, PL 수를 추출하여 출력 엑셀 상단에 표시

## 파레트 계산

박스수량을 기반으로 필요한 파레트 수를 계산한다.

### 파레트당 박스 수 기준
- **기본값 (이더컴퍼니, 클린인테크 등)**: 1파레트 = **16박스**
- **이든코퍼레이션 캐리어 커버**: 1파레트 = **22박스** (캐리어 커버는 박스 크기가 작아서 더 많이 들어감)
- **마인플로 신발정리대**: 1파레트 = **12박스** (신발정리대는 박스 크기가 커서 적게 들어감)
- 특수 기준에 해당하지 않는 상품은 모두 16박스/파레트 적용

### 판별 로직
1. Row 1의 회사명에서 사업자 확인
2. 라벨명(H열)에서 특수 상품 키워드 확인:
   - "이든코퍼레이션" + "캐리어 커버" → 22박스/파레트
   - "마인플로" + "신발정리대" → 12박스/파레트
   - 그 외 → 16박스/파레트

### 표시 형식
- 나누어 떨어지는 경우: `{N}파레트`
- 나머지가 있는 경우: `{N}파레트 {M}박스 (올림 시 {N+1}파레트)`
- 괄호 안에 기준도 표시: `({X}박스/파레트)`

예시:
- 40박스 ÷ 16 = `2파레트 8박스 (올림 시 3파레트) (16박스/파레트)`
- 32박스 ÷ 16 = `2파레트 (16박스/파레트)`
- 44박스 ÷ 22 = `2파레트 (22박스/파레트)`
- 25박스 ÷ 12 = `2파레트 1박스 (올림 시 3파레트) (12박스/파레트)`

## 출력 엑셀 형식

openpyxl을 사용하여 다음 구조의 엑셀을 생성한다:

### 레이아웃
| 행 | 내용 | 스타일 |
|---|---|---|
| Row 1 | `{문서번호} 출고수량 정리 ({회사명})` | 볼드 14pt, 좌측정렬 |
| Row 2 | `총 박스수량: {N}박스 ({N}상자 + {N}PL)` | 볼드 12pt, 초록 배경(#E2EFDA) |
| Row 3 | `파레트: {파레트 텍스트} ({X}박스/파레트)` | 볼드 12pt, 주황 배경(#FCE4D6) |
| Row 4 | 안내문구: 세트수량 기준 설명 + 오름차순 정렬 | 회색 9pt |
| Row 5 | (빈 행) | |
| Row 6 | 헤더: 상품명, 옵션, 출고수량(K), 세트수량(L), 적용수량, 적용기준 | 흰색 볼드, 파란 배경(#2F5496) |
| Row 7~ | 데이터 행 (상품명·옵션 오름차순 정렬) | |
| 소계 행 | 상품별 소계 | 볼드, 연파란 배경(#D6E4F0) |
| 총합 행 | 총 출고수량 | 흰색 볼드 12pt, 파란 배경(#2F5496) |

### 정렬
- 상품명 오름차순 → 옵션 오름차순으로 정렬

### 하이라이트
- 세트수량(L열)이 적용된 행은 적용수량·적용기준 셀에 노란 배경(#FFF2CC) 표시
- 사용자가 한눈에 "이건 세트수량 기준이구나" 파악할 수 있도록 하기 위함

### 열 너비
- A(상품명): 42, B(옵션): 28, C~F: 14

### 소계 구조
- 같은 상품의 옵션들이 끝나면 소계 행 삽입
- 소계 행은 A~D열 병합, E열에 해당 상품 합계

## 파일 저장

- 파일명: `{원본 문서번호}_출고수량정리.xlsx` (예: `S-QED260407_출고수량정리.xlsx`)
- 문서번호는 Row 1 텍스트에서 `S-QED\d+` 패턴으로 추출
- 사용자의 작업 폴더에 저장하고 computer:// 링크 제공

## 구현 시 주의사항

- `pip install openpyxl`이 필요할 수 있음 (`--break-system-packages` 플래그 사용)
- 데이터는 Row 3부터 시작 (Row 1: 제목, Row 2: 헤더)
- 열 인덱스는 0-based: H=7, K=10, L=11
- 라벨명 파싱 시 `split(', ', 1)`로 첫 번째 쉼표만 분리 (옵션에 쉼표가 포함될 수 있음)
- 빈 라벨명 행은 건너뛰기
- Border는 모든 데이터 셀에 thin 적용
- math.ceil 사용하여 올림 파레트 수 계산
