# 실배송 자동 처리 (스마트스토어/쿠팡 → 사방넷)

## 개요

사용자가 스마트스토어 또는 쿠팡에서 다운로드한 주문 엑셀 파일을 업로드하면,
사방넷(3PL 물류대행) 발주등록 양식 엑셀로 자동 변환하여 사용자의 다운로드 폴더에 저장한다.
사용자가 직접 사방넷풀필먼트에 업로드하는 방식이다.

### 사방넷 계정 구조

사방넷 계정은 2개이며, 상품코드 접두사로 구분한다:

| 사방넷 계정 | 코드 접두사 | 소속 사업자 | 상품 유형 |
|-------------|-------------|-------------|-----------|
| **뉴트리정** | N | 뉴트리정 | 건강기능식품 (영양제) |
| **이더컴퍼니** | E | 이더컴퍼니, 클린인테크, 마인플로, 이든코퍼레이션, 루미솔 | 공산품 (깔창, 운동화, 양말, 베개 등) |

## 처리 흐름

### STEP 1: 엑셀 변환
1. 사용자가 주문 엑셀 업로드 (스마트스토어, 쿠팡, 또는 둘 다 — 파일별 자동 감지)
2. (선택) 재고조회 파일 업로드 — 새 상품이 추가됐을 때만 필요
3. 스크립트 `scripts/convert_smartstore.py` 실행 (--input에 여러 파일 동시 전달 가능)
4. 소스(스마트스토어/쿠팡) 구분 없이 사방넷 계정별로 통합하여 엑셀 출력 (뉴트리정용, 이더컴퍼니용)

### STEP 2: 사용자에게 전달
5. 변환된 엑셀 파일을 **사용자의 다운로드 폴더**에 저장
6. 사용자에게 변환 결과 요약 및 검수 요청
7. 사용자가 직접 사방넷풀필먼트에 업로드

## 실행 방법

```bash
python3 <skill-path>/scripts/convert_smartstore.py \
  --input <주문파일1.xlsx> [<주문파일2.xlsx> ...] \
  --output <출력경로/사방넷_발주등록_YYYYMMDD.xlsx> \
  [--source smartstore|coupang] \
  [--inventory <재고조회파일.xlsx>] \
  [--no-split]
```

- `--input`: 주문 엑셀 파일 경로 (여러 개 가능, 스마트스토어와 쿠팡 혼합 가능 — 파일별로 소스 자동 감지)
- `--output`: 출력할 사방넷 발주등록 엑셀 경로 (계정별 분리 시 `_뉴트리정.xlsx`, `_이더컴퍼니.xlsx` 접미사 추가)
- `--source`: (선택) 모든 입력 파일의 소스를 강제 지정. 미지정 시 파일별로 파일명/시트명으로 자동 감지
- `--inventory`: (선택) 재고조회 엑셀 파일 — 매핑 테이블에 없는 새 상품이 있을 때 사용
- `--no-split`: (선택) 계정별 분리 없이 단일 파일로 출력

**여러 파일을 동시에 넣으면, 소스(스마트스토어/쿠팡) 구분 없이 같은 계정끼리 자동으로 합쳐져서 계정별 엑셀 1개씩 출력된다.**

### 소스 자동 감지 규칙
- 파일명에 "스마트스토어" → smartstore
- 파일명에 "DeliveryList" 또는 "Delivery" → coupang
- 시트명 "발주발송관리" → smartstore
- 시트명 "Delivery" → coupang

### 출력 파일은 반드시 사용자의 다운로드 폴더에 저장
출력 경로를 사용자의 Downloads 폴더(`/sessions/.../mnt/Downloads/`)로 지정하여,
사용자가 바로 파일을 찾을 수 있게 한다.

## 입력 파일 형식

### 스마트스토어 주문 엑셀
- 파일명 패턴: `스마트스토어_전체주문발주발송관리_YYYYMMDD_HHMM.xlsx`
- 시트명: `발주발송관리`
- 1행은 안내 텍스트, 2행이 실제 헤더
- 필요한 컬럼: 상품주문번호, 상품번호, 상품명, 옵션정보, 수량, 수취인명, 수취인연락처1, 통합배송지, 우편번호, 배송메세지

### 쿠팡 DeliveryList 엑셀
- 파일명 패턴: `DeliveryList(YYYY-MM-DD)_(...).xlsx`
- 시트명: `Delivery`
- 1행이 헤더
- 필요한 컬럼: 주문번호, 등록상품명, 등록옵션명, 구매수(수량), 수취인이름, 수취인전화번호, 우편번호, 수취인 주소, 배송메세지

### 재고조회 엑셀
- 파일명 패턴: `재고조회(기본)_YYYY-MM-DD_HHMMSS.xlsx`
- 1행 헤더, 주요 컬럼: 상품코드(3번째), 출고상품명(4번째)

## 출력 파일 형식 (사방넷 발주등록)

23개 컬럼, 시트명은 반드시 `발주등록_sample`:

| 컬럼 | 필수 | 설명 |
|------|------|------|
| **상품고유코드** | ✅ | 사방넷 상품코드 (예: E00400004, N00200001) |
| **판매상품명** | ✅ | 출고상품명 |
| **수량** | ✅ | 실제 출고 수량 (세트/이벤트/개수 반영) |
| **배송방식** | ✅ | 항상 "택배" |
| 주문자 이름 | | 비워둠 |
| **받는분 이름** | ✅ | 수취인명 |
| **전화번호1** | ✅ | 수취인연락처 |
| 전화번호2 | | 비워둠 |
| **우편번호** | ✅ | 우편번호 |
| **주소1** | ✅ | 배송지 주소 |
| 주소2 | | 비워둠 |
| 배송메세지 | | 있으면 넣음 |
| 주문번호 | | 추적용 |
| 관리메모1~5 | | 비워둠 |
| 상품별 메모1~3 | | 비워둠 |
| 발주 타입 | | 비워둠 |
| 출고희망일 | | 비워둠 |

## 상품 매핑 규칙

매핑 데이터는 `scripts/product_mapping.json`에 저장된다.

### 스마트스토어 매핑 (상품번호별_매핑)
- 상품번호 + 옵션(색상/사이즈) → 사방넷 코드
- 깔창류: 색상_사이즈 키 (예: "블랙_245-250" → "E00400331")
- 영양제류: _default 키 (예: "_default" → "N00200007")

### 쿠팡 매핑 (쿠팡_매핑)
- 등록상품명 + 등록옵션명 → 사방넷 코드
- 키 형식: "등록상품명|등록옵션명" (정확 매칭)
- 와일드카드: "등록상품명|*" (옵션 무관 매칭, 영양제 등)
- 예: "뉴트리정 활력 비타민B 에너지 플러스 대용량|*" → "N00200017"
- 예: "바디인솔 프리미엄 무지 중목 양말, 20켤레|화이트 FREE" → "E00400023"

### 수량 변환 규칙

**스마트스토어:**
- 세트 옵션: 1+1→×1, 2+2→×2, 3+3→×3 (세트배수 × 주문수량)
- 할인이벤트: "할인이벤트: N개" → N × 주문수량

**쿠팡:**
- 등록옵션명에서 "N개" 또는 "N박스" 파싱 → N × 구매수(수량)
- 개/박스 표시 없으면 구매수 그대로 (예: 양말 "화이트 FREE")

### 계정별 자동 분류
- N코드 → 뉴트리정 계정
- E코드 → 이더컴퍼니 계정

## 매핑 실패 처리

매핑되지 않는 상품이 있으면:
1. 상품고유코드를 "???"로 표시
2. 변환 완료 후 매핑 실패 건을 사용자에게 알림
3. 사용자가 재고조회 파일을 추가로 제공하면 매핑 업데이트

## 주의사항

- 사방넷 양식의 시트명은 반드시 `발주등록_sample`이어야 한다
- 주문자 이름은 비워둔다 (사방넷에서 불필요)
- 배송메세지가 없는 경우(NaN) 빈 문자열로 처리
- 우편번호는 문자열로 유지 (앞자리 0 보존)
- 매핑 실패("???")가 있는 엑셀은 사용자에게 확인 요청
- **사방넷 사이트에 직접 업로드하지 않는다** — 엑셀 파일만 다운로드 폴더에 생성하고 사용자가 직접 업로드
