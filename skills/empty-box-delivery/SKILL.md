# 빈박스 운송장 자동 매칭

## 개요

이더컴퍼니에서 운영하는 쿠팡 로켓그로스 사업자(마인플로, 클린인테크, 뉴트리정, 이더컴퍼니 등)의 빈박스 배송 처리를 자동화하는 스킬이다.

빈박스란 체험단 주문에 대해 실물 대신 빈 박스를 발송하고, 쿠팡에 운송장을 등록하는 프로세스를 말한다. 매일 반복되는 업무이며, 수작업으로 하면 VLOOKUP·서식변환·복사 등에 시간이 많이 든다.

## 입력 파일

### 방법 1: DeliveryList만 전달 (권장 — 3PL 파일 자동 탐색)

사용자가 DeliveryList만 업로드하면, 3PL 송장 파일은 카카오톡 받은 파일 폴더에서 자동으로 찾는다.

- 카카오톡 받은 파일 경로: `C:\Users\이더컴퍼니\Documents\카카오톡 받은 파일`
- 카카오톡 폴더가 마운트되어 있지 않으면 `mcp__cowork__request_cowork_directory`로 `~/Documents/카카오톡 받은 파일`을 먼저 마운트
- 오늘 날짜(MM DD 형식)가 파일명에 포함된 `3pl` 파일을 자동 검색
- 찾은 파일 목록을 사용자에게 보여주고 확인 후 진행

### 방법 2: 모든 파일 직접 업로드 (수동)

사용자가 DeliveryList와 3PL 파일을 모두 업로드하면 업로드된 파일만 사용한다.

### DeliveryList 엑셀
- 파일명 패턴: `DeliveryList(YYYY-MM-DD)_(N).xlsx`
- 쿠팡에서 다운로드한 출고요청서
- 핵심 열 구조:
  - C열(col 3): 주문번호 — 매칭 키로 사용
  - E열(col 5): 운송장번호 — 비어 있음, 사용자가 수동 붙여넣기할 곳
- 1행은 헤더, 2행부터 데이터

### 3PL 체험단 송장 엑셀
- 파일명 패턴: `3pl C 체험단 [상품명] MM DD_[숫자].xlsx`
- 3PL 업체에서 발급한 송장 목록
- 핵심 열 구조:
  - A열(col 1): 주문번호
  - K열(col 11): CJ대한통운 송장 — 형식: `6972-8547-9320` (하이픈 포함)
  - L열(col 12): 롯데택배 송장 — CJ가 없을 때 폴백
- 1행은 헤더, 2행부터 데이터

## 처리 프로세스

### 1단계: 파일 분류 및 3PL 자동 탐색

업로드된 파일들을 자동 분류한다:
- 파일명에 `DeliveryList`가 포함되면 → 쿠팡 출고요청서
- 파일명에 `3pl` 또는 `체험단`이 포함되면 → 3PL 송장 파일
- 분류가 애매하면 사용자에게 확인 요청

**3PL 파일이 업로드되지 않은 경우 (DeliveryList만 전달된 경우):**
1. 카카오톡 받은 파일 폴더를 마운트한다
2. 스크립트에 `--kakao-dir` 옵션으로 카카오톡 폴더 경로를 전달한다
3. 스크립트가 오늘 날짜의 3PL 파일을 자동으로 찾아서 사용한다

**미매칭 재매칭 요청 시 (이전 날짜 탐색):**
사용자가 미매칭 건에 대해 "다시 매칭해줘", "전날짜 파일로 매칭해줘" 등을 요청하면,
`--search-days 7` 옵션을 추가하여 최근 7일간의 3PL 파일을 모두 탐색한다.
이렇게 하면 이전 날짜에 발급된 송장도 자동으로 찾아서 매칭할 수 있다.

### 2단계: 매핑 테이블 생성

모든 3PL 송장 파일에서 주문번호와 송장번호를 추출하여 매핑 테이블을 만든다:
- 주문번호(A열) → 문자열 정리 후 정수 변환
- 송장번호(K열, 없으면 L열) → **하이픈("-") 모두 제거** 후 정수 변환
- 예: `6972-8547-9320` → `697285479320`

### 3단계: 운송장번호 매칭

DeliveryList의 각 행에 대해 주문번호(C열)를 키로 매핑 테이블을 조회하여 운송장번호를 찾는다.
DeliveryList의 행 순서를 그대로 유지하여 운송장번호 목록을 생성한다.

**중요: 쿠팡 DeliveryList 엑셀은 보안/접근제한이 걸려 있어서 직접 수정 후 저장하면 파일이 깨진다. 따라서 DeliveryList 엑셀 파일을 절대 수정하지 않는다.**

### 4단계: 결과 출력

**운송장번호만 들어있는 복사용 엑셀 파일을 생성한다**: `운송장번호_복사용.xlsx`
- A열에 DeliveryList의 주문번호 순서 그대로 운송장번호를 나열
- 매칭되지 않은 행은 빈 셀로 남겨둠
- xlsxwriter로 새로 생성하는 깨끗한 엑셀이라 정상적으로 열림

**반드시 사용자의 다운로드 폴더에 직접 저장한다.**
- Cowork의 present_files나 outputs 폴더를 거치면 파일이 안 열리는 문제가 있으므로, 반드시 마운트된 다운로드 폴더에 직접 저장할 것
- 다운로드 폴더가 마운트되어 있지 않으면 `mcp__cowork__request_cowork_directory`로 `~/Downloads`를 먼저 마운트

**사용자의 사용법:**
1. 다운로드 폴더에서 운송장번호_복사용.xlsx 열기
2. A열 드래그 → 복사(Ctrl+C)
3. 쿠팡 DeliveryList의 운송장번호(E열) 첫 칸에 붙여넣기(Ctrl+V)

## 스크립트 사용법

번들된 스크립트로 전체 프로세스를 한 번에 실행할 수 있다:

### 방법 1: DeliveryList 전달 + 카카오톡 폴더에서 3PL 자동 탐색 (권장)

```bash
python3 <skill-path>/scripts/process_delivery.py \
  --delivery "<DeliveryList 파일 경로>" \
  --kakao-dir "<카카오톡 받은 파일 폴더 마운트 경로>" \
  --output-dir "<다운로드 폴더 경로>"
```

### 방법 2: 이전 날짜까지 포함하여 탐색 (미매칭 재처리용)

```bash
python3 <skill-path>/scripts/process_delivery.py \
  --delivery "<DeliveryList 파일 경로>" \
  --kakao-dir "<카카오톡 받은 파일 폴더 마운트 경로>" \
  --search-days 7 \
  --output-dir "<다운로드 폴더 경로>"
```

### 방법 3: 3PL 파일 직접 지정 (기존 방식)

```bash
python3 <skill-path>/scripts/process_delivery.py \
  --delivery "<DeliveryList 파일 경로>" \
  --tracking "<3PL 파일1>" "<3PL 파일2>" ... \
  --output-dir "<다운로드 폴더 경로>"
```

스크립트는 운송장번호_복사용.xlsx를 생성하며, 처리 결과(매칭 건수, 미매칭 건수)를 출력한다.

## 검증 포인트

처리 완료 후 반드시 확인할 사항:
- 전체 주문 건수 대비 매칭 성공/실패 건수 리포트
- 매칭 실패(미입력) 건이 있으면 사용자에게 알림 — 누락된 송장 파일이 있을 수 있음

## 엣지 케이스

- **3PL 파일에 롯데택배 송장(L열)만 있고 CJ 송장(K열)이 비어있는 경우**: L열(col 12)에서 송장번호를 가져온다
- **같은 주문번호가 여러 3PL 파일에 중복되는 경우**: 먼저 발견된 매핑을 사용하되, 충돌이 있으면 사용자에게 알린다
- **DeliveryList에 이미 운송장번호가 채워진 행**: 건너뛴다 (이미 처리된 건)
- **주문번호가 숫자로 변환 불가능한 경우**: 해당 행을 건너뛰고 경고 출력
- **카카오톡 폴더에 오늘 날짜 3PL 파일이 없는 경우**: 사용자에게 알리고, 직접 업로드를 요청
- **미매칭 재매칭 요청 시**: `--search-days 7`로 최근 7일간 3PL 파일을 탐색하여 이전 날짜 송장까지 매칭
