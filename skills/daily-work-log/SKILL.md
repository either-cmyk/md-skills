## 목표
오늘 하루 동안 이 프로젝트에서 수행한 업무를 파악하고, 노션 업무일지 캘린더의 오늘 날짜 페이지 안 보드 DB에 "진행 중" 상태로 추가한다.

## 제외 대상 (매일/주간 루틴 업무)
아래에 해당하는 업무는 절대 추가하지 않는다:
- 빅셀 일일 업데이트 (모든 사업자)
- 실배송 처리 (사방넷 발주등록)
- 할인쿠폰 삽입, CS업무
- 상품순회, 판매량 체크, 상품수정
- 발주 체크
- 물류현황 체크, 입고 생성, FBC 작업지시
- 쿠팡 이슈확인
- 결제건 업로드, 소싱
- 시트 최신화, 상품 클릭순회, 물류사이즈/재고 순회
- 반품상품 보관비 확인, 반품률/고객의견 파악

위 루틴에 해당하지 않는, 따로 시간 내서 한 작업만 추가한다.

## 실행 절차

### 1단계: 노션 업무일지 페이지 찾기
- 김현기 업무일지 캘린더 DB (URL: https://www.notion.so/174d9e7503678013aa08eebe5b7377ed, data source: collection://a3869f55-d417-4bdc-8486-dc0f4bbac831)에서 오늘 날짜의 "업무일지" 페이지를 검색한다.
- 해당 페이지 안에 인라인 DB(보드)가 있다. 그 보드의 data source URL을 fetch로 확인한다.
- ⚠️ **보드에 이미 "진행 중" 항목이 몇 개 있든 절대 건너뛰지 않는다.** 기존 항목은 사용자가 수동으로 미리 등록해 둔 것이므로 "이미 업데이트 완료"로 판단하면 안 된다. 기존 항목은 그대로 두고 오늘 파악한 업무를 이어서 추가한다.
- 단, 오늘 파악한 업무가 기존 항목과 **내용이 같으면** 그 건만 중복으로 보고 제외한다.

### 2단계: 오늘 작업 내역 파악
- `list_sessions` 도구로 최근 세션 목록을 가져온다.
- 오늘 날짜에 활동이 있었던 세션들의 `read_transcript`를 읽어 어떤 업무를 했는지 파악한다.
- 제외 대상에 해당하는 루틴 업무는 걸러낸다.

### 3단계: 추가할 항목이 있는지 확인
- 루틴 외 업무가 없으면 "오늘은 루틴 외 추가 업무가 없어서 업무일지에 넣을 항목이 없습니다"라고 보고하고 종료한다.

### 4단계: 보드에 항목 추가
- 보드 DB에 create-pages로 항목을 추가한다.
- 각 항목: 이름 = 업무 제목 (간결하게), 상태 = "진행 중"
- **큰 업무만 넣지 않는다.** 손이 갔던 짜잘한 일, 오류 수정, 엣지케이스 처리도 모두 별도 항목으로 추가한다.
- 상세 설명 없이 제목만 넣는다.

### 5단계: 결과 보고
- 추가한 항목 목록을 간단히 보고한다.
