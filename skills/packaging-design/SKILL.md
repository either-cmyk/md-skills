# 패키징 디자인 요청서 자동화

상품 패키징(박스) 디자인의 전체 워크플로우를 자동화한다.
3가지 핵심 기능: (1) 노션 디자인 가이드 작성, (2) HTML 목업 생성, (3) 칼선 PDF 검수.

---

## 워크플로우 개요

```
사용자 요청 → 상품 정보 수집 → 노션 디자인 가이드 작성 → HTML 목업 생성 → (디자이너 작업) → 칼선 PDF 검수
```

사용자가 어느 단계를 요청하느냐에 따라 해당 단계부터 진행한다.
- "패키징 디자인 요청서 만들어줘" → Phase 1부터
- "목업 만들어줘" → Phase 2부터
- "칼선 파일 확인해줘" → Phase 3부터

---

## Phase 1: 노션 디자인 가이드 작성

### 1-1. 사용자에게 수집할 정보

시작 전 아래 정보를 확인한다. 사용자가 이미 제공한 항목은 건너뛴다.

**필수 정보:**
- 상품명 (브랜드명 + 제품명)
- 박스 사이즈 (높이 × 가로 × 깊이, cm 단위)
- 옵션 구성 (색상, 수량 등)
- 사업자명 (수입원/제조원)
- 제조국
- 재질 정보
- 규격 (개별 상품 크기)

**선택 정보:**
- 경쟁사 레퍼런스 이미지
- AI 예시 이미지
- 투명 창 여부 및 사이즈
- 특장점 키워드 (3~4개)
- 사용 방법 단계
- 취급 주의사항
- 바코드 번호
- 브랜드 컬러
- 칼선 파일 (PDF)

### 1-2. 노션 페이지 구조

아래 구조로 노션 페이지 콘텐츠를 작성한다. `notion-update-page`의 `update_content` 커맨드로 내용을 채운다.

```
📦 [상품명] 패키징

├── 📦 경쟁사 레퍼런스 (토글)
│   └── 레퍼런스 1~N (컬럼 레이아웃 + 이미지)
│
├── 📦 [브랜드] [상품명] 패키징 디자인 (토글)
│   ├── 📸 디자인 예시 (토글) — AI 이미지 등
│   └── 📍 구역 표시 (토글) — 구역 표시된 와이어프레임
│
├── 1️⃣ 앞면 디자인 가이드 (토글)
│   ├── 🅰️ 구역 A — 상단 브랜드 영역
│   ├── 🅱️ 구역 B — 상품명 + 옵션 영역
│   ├── ©️ 구역 C — 특장점 아이콘 영역
│   ├── 🅳 구역 D — 투명 창 / 제품 이미지 영역
│   ├── 🅴 구역 E — 하단 브랜드 영역
│   ├── 🎨 배경
│   └── 투명 창 / 배경 컬러 (토글)
│
├── 2️⃣ 뒷면 디자인 가이드 (토글)
│   ├── 🅰️ 구역 A — 상단 헤더 영역
│   ├── 🅱️ 구역 B — 사용 방법 영역
│   ├── ©️ 구역 C — 품질표시 + 주의사항 영역
│   └── 🅳 구역 D — 하단 바코드 + 재활용 마크 영역
│
├── 3️⃣ 측면 디자인 가이드 (토글)
│
├── 4️⃣ 공통 사항 (토글)
│   ├── 🎨 컬러 가이드
│   ├── ✍️ 폰트 가이드
│   ├── 🖨️ 인쇄 사양
│   ├── 📦 납품 파일
│   └── ⚠️ 참고 사항
│
├── 5️⃣ 옵션별 패키징 구분 (토글)
│
└── 칼선 파일 (토글)
    ├── 📐 전개도 면 배치 안내
    └── 첨부파일
```

### 1-3. 구역별 테이블 형식

각 구역은 아래 테이블 형식으로 작성한다:

```markdown
### [이모지] 구역 [알파벳] — [구역명] {color="[색상]_bg"}

<table header-row="true">
<colgroup><col><col width="400"></colgroup>
<tr><td>항목</td><td>내용</td></tr>
<tr><td>위치</td><td>[위치 설명]</td></tr>
<tr><td>텍스트</td><td>[텍스트 내용]</td></tr>
<tr><td>폰트</td><td>[폰트 지정]</td></tr>
<tr><td>색상</td><td>[색상 지정]</td></tr>
<tr><td>아이콘</td><td>[아이콘 설명]</td></tr>
<tr><td>참고</td><td>[참고 사항]</td></tr>
</table>
```

**구역 색상 규칙:**
- 구역 A: `blue_bg`
- 구역 B: `green_bg`
- 구역 C: `yellow_bg`
- 구역 D: `purple_bg`
- 구역 E: `red_bg`
- 배경/기타: `gray_bg`

### 1-4. 앞면 구역 가이드 (기본 5구역)

| 구역 | 역할 | 핵심 내용 |
|------|------|-----------|
| A | 상단 브랜드 | 브랜드 로고 + 서브 카피. 메인컬러 배경 + 흰색 텍스트 |
| B | 상품명+옵션 | 브랜드명 + 상품명(줄바꿈 시 `/` 사용) + 옵션 뱃지(색상, 수량). 텍스트 테두리 효과 |
| C | 특장점 아이콘 | 3~4개 원형 아이콘 + 짧은 텍스트. 가로 균등 배치 |
| D | 투명 창/이미지 | 제품 실물이 보이는 OPP 필름 투명 창 또는 제품 이미지 |
| E | 하단 브랜드 | 브랜드명 + 영문 서브 카피 |

**상품명 표기 규칙:**
- 패키징 앞면(B구역): `브랜드명 서브네임 / 핵심 상품명` — `/`는 줄바꿈 위치를 나타냄
- 품질표시(뒷면): 정식 명칭 (슬래시 없이 한 줄로)
- 예) 앞면: "슬루나 스크래치 제로 / 양면 스펀지 수세미" → 품질표시: "슬루나 스크래치 제로 양면 스펀지 수세미"

### 1-5. 뒷면 구역 가이드 (기본 4구역)

| 구역 | 역할 | 핵심 내용 |
|------|------|-----------|
| A | 상단 헤더 | 앞면과 동일한 브랜드 바 |
| B | 사용 방법 | "이렇게 사용하세요" + 3~5단계 (아이콘+번호+제목+설명 세트) |
| C | 품질표시+주의사항 | 좌측 품질표시(테이블) + 우측 취급 주의사항(번호 목록). 2열 병렬 배치 |
| D | 바코드+재활용 | 좌측 바코드 + 우측 PP/비닐류 재활용 마크 |

### 1-6. 공통 사항 섹션

반드시 포함해야 할 항목:

- 🎨 컬러 가이드 — 메인 컬러, 앞/뒷/측면 톤 통일
- ✍️ 폰트 가이드 — 상품명(볼드+테두리), 본문(산세리프)
- 🖨️ 인쇄 사양 — CMYK, 재단여백 3mm, 300dpi
- 📦 납품 파일 — AI 또는 PSD 원본 + PDF 확인용, 폰트 아웃라인 처리
- ⚠️ 참고 사항 — AI 예시와 유사하게, 투명 창 영역 주의

### 1-7. 칼선 파일 섹션

```
- 사이즈: [높이]*[가로]*[깊이]cm
- 📐 전개도 면 배치 안내 (토글)
  - 상단 플랩: [메인컬러]로 통일
  - 하단 플랩: 화이트로 통일
  - 전개도 이미지/PDF 첨부
```

### 1-8. 최종 검수 체크리스트 (디자이너 관점)

노션 페이지 작성 완료 후, 디자이너 관점에서 아래 항목을 전수 점검한다:

- 박스 치수가 일관되게 명시되어 있는가
- 모든 구역에 텍스트 내용이 빠짐없이 채워져 있는가
- 품질표시 항목이 모두 있는가 (제품명, 재질, 규격, 수입원/제조원, 제조국, 색상, 구성)
- 주의사항이 해당 제품군에 적합한가
- 앞면 상품명과 뒷면 품질표시 제품명이 일치하는가 (슬래시 유무 차이만 허용)
- 컬러/폰트/인쇄 사양이 명확한가
- 납품 파일 형식이 명시되어 있는가
- 칼선 파일 또는 치수 정보가 있는가
- 맞춤법·띄어쓰기 오류가 없는가

## Phase 2: HTML 목업 생성

`show_widget` 도구로 패키징 전개도 목업을 HTML로 생성한다.

### 2-1. 목업 구성

전개도 기준으로 앞면·뒷면·측면을 한 화면에 배치한다.
실제 박스 비율(높이:가로:깊이)을 정확히 반영한다.

### 2-2. 목업에 포함할 요소

- 각 면의 구역 구분선 + 알파벳 라벨
- 실제 텍스트 (상품명, 특장점, 품질표시 등)
- 메인 컬러 배경
- 투명 창 영역 표시 (점선)
- 상하단 플랩 (접히는 부분)
- mm 단위 치수 표기

### 2-3. 목업 레이아웃 기본 구조

```
[상단 플랩 - 메인컬러]
[앞면 (W)] [측면 (D)] [뒷면 (W)] [측면 (D)]
[하단 플랩 - 화이트]
```

각 패널의 너비는 박스 치수에 비례하여 배치한다.
높이(H)는 모든 패널 공통. 플랩 높이는 보통 5~6cm.

## Phase 3: 칼선 PDF 검수

완성된 칼선(전개도) PDF 파일을 검수한다.

### 3-1. 치수 검증

PDF를 PyMuPDF(fitz)로 열어 페이지 크기를 확인한다:

```python
import fitz
doc = fitz.open(pdf_path)
page = doc[0]
rect = page.rect
print(f'Page size: {rect.width} x {rect.height}')
```

박스 사이즈 `H×W×D`에 대해:
- 전개도 가로: `(W + D) × 2` cm
- 전개도 세로: `H` cm
- 상하 플랩: 보통 5~6cm씩

### 3-2. 텍스트 검증

PDF에서 텍스트 추출을 시도한다. 벡터/이미지 기반이면 고해상도 렌더링 후 시각적으로 확인한다:

```python
# 텍스트 추출 시도
text = page.get_text('text')

# 텍스트가 없거나 부족하면 고해상도 렌더링
if not text.strip() or len(text.strip()) < 50:
    # 전체 페이지 3x 렌더링
    mat = fitz.Matrix(3, 3)
    pix = page.get_pixmap(matrix=mat)
    pix.save('full_page.png')
    
    # 세부 영역 5x 렌더링 (품질표시, 주의사항 등 작은 글씨)
    # 뒷면 하단 영역 (품질표시+주의사항)
    clip = fitz.Rect(rect.width*0.5, rect.height*0.55, rect.width*0.95, rect.height*0.88)
    mat2 = fitz.Matrix(5, 5)
    pix2 = page.get_pixmap(matrix=mat2, clip=clip)
    pix2.save('detail_quality.png')
    
    # 뒷면 상단 영역 (사용법)
    clip3 = fitz.Rect(rect.width*0.5, rect.height*0.2, rect.width*0.95, rect.height*0.58)
    pix3 = page.get_pixmap(matrix=mat2, clip=clip3)
    pix3.save('detail_usage.png')
    
    # 앞면 영역
    clip4 = fitz.Rect(rect.width*0.05, rect.height*0.15, rect.width*0.38, rect.height*0.85)
    pix4 = page.get_pixmap(matrix=mat2, clip=clip4)
    pix4.save('detail_front.png')
```

Read 도구로 렌더링된 이미지를 열어 텍스트를 한 글자씩 확인한다.

### 3-3. 검수 체크리스트

**치수:**
- 전개도 전체 크기가 박스 사이즈와 일치하는가
- 각 면(앞면, 뒷면, 측면)의 비율이 올바른가
- 플랩 크기가 적절한가

**텍스트:**
- 앞면 상품명이 정확한가
- 옵션 뱃지(색상, 수량)가 올바른가
- 특장점 텍스트가 맞는가
- 사용 방법 단계가 올바른가
- 품질표시 전 항목이 정확한가
- 취급 주의사항이 빠짐없는가
- 영문 텍스트 스펠링이 맞는가

**맞춤법:**
- 모든 한글 텍스트의 맞춤법·띄어쓰기를 한 글자씩 검증
- 종결어미 통일 확인 (~마십시오, ~하십시오)
- 작은 글씨(품질표시, 주의사항)는 확대 렌더링 후 반드시 확인

**디자인:**
- 상단 플랩 색상이 맞는가 (메인 컬러)
- 하단 플랩 색상이 맞는가 (화이트)
- 바코드 + 재활용 마크가 있는가
- 투명 창 위치/크기가 적절한가

### 3-4. 노션 가이드 대비 크로스체크

노션 페이지 ID가 있으면 `notion-fetch`로 원본 가이드를 불러와서 PDF 내용과 대조한다:
- 노션 품질표시 항목 vs PDF 품질표시 항목
- 노션 주의사항 vs PDF 주의사항
- 노션 특장점 vs PDF 특장점 아이콘 텍스트

---

## 주의사항

### 맞춤법 검수 원칙
- 모든 텍스트 작성 시 맞춤법·띄어쓰기를 반드시 검토 후 작성한다
- PDF 검수 시 작은 글씨는 반드시 확대(5x) 렌더링하여 한 글자씩 확인한다
- "~하지마십시오" → "~하지 마십시오" (띄어쓰기 주의)

### 노션 마크다운 문법
- 토글: `<details><summary>제목</summary>내용</details>`
- 테이블: `<table header-row="true"><tr><td>...</td></tr></table>`
- 강조: `<span color="red">**텍스트**</span>`
- 페이지 링크: `<mention-page url="https://www.notion.so/[page-id]"/>`
- 색상 헤더: `### 제목 {color="blue_bg"}`
