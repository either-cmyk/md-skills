# 쿠팡 팔레트 적재리스트 생성 스킬 (2026.04.21 신양식)

## 개요

동봉문서(거래명세서) PDF + CN인사이더 출고내역 엑셀 두 파일을 받아 **팔레트별 1페이지**로 구성된 적재리스트 PDF를 생성한다. 박스번호는 **팔레트 단위**로 자동 계산된다.

## 사용자가 제공해야 하는 2가지 입력

1. **물류동봉문서 PDF** (쿠팡 거래명세서)
2. **CN인사이더 출고내역 엑셀** (FBC창고 → 입고제품 → 해당 건 상세의 "Excel 다운로드")

## 신양식 핵심 규칙

- **페이지 1개 = 팔레트 1개**
- **팔레트 번호** = `{총 팔레트수}-{해당 팔레트 순번}` (예: `14-1`)
- **총 박스 필드** = 해당 팔레트 박스수 (페이지마다 달라짐. 예: 팔레트 1~8은 12, 팔레트 9는 11)
- **박스 번호** = `{해당 팔레트 박스수}-{팔레트 내 박스 순번}` (예: 16박스 팔레트의 5번째 박스면 `16-5`)
- **혼적박스만 박스번호 기재**, 단독박스는 공란
- **상품 목록은 해당 팔레트에 실제 적재된 상품만** 표시
- 같은 SKU가 여러 혼적박스에 걸치면 **박스마다 별도 행**
- 단독박스 상품들은 **SKU별 합산 1행** (box_no 공란)

## 작업 흐름

### 1단계: 출력 경로 확인

PDF 저장 경로: `C:\Users\이더컴퍼니\Downloads\적재리스트_{발주번호}.pdf`

세션에서 Downloads 폴더 미연결이면 먼저 연결:
```
request_cowork_directory(path="C:\\Users\\이더컴퍼니\\Downloads")
```

### 2단계: 파서 실행 (동봉 PDF + CN 엑셀 → JSON)

```bash
python <skill_path>/scripts/parse_inputs.py \
  --dongbong-pdf <동봉문서 PDF 경로> \
  --cn-excel <CN 엑셀 경로> \
  --output-json <임시 JSON 경로>
```

이 스크립트가 자동으로 수행:
- 동봉 PDF에서 업체·발주번호·팔레트수·상품(바코드 포함) 파싱
- CN 엑셀에서 팔레트별 박스 내용 파싱
- 바코드로 동봉 상품 ↔ 엑셀 박스 내용 매칭
- 혼적박스 감지 및 팔레트 내 박스순번 계산
- 팔레트별 rows 생성 (단독 합산 + 혼적 분리)
- 교차검증 경고 (`_warnings`)

### 3단계: PDF 생성

```bash
python <skill_path>/scripts/generate_loading_list.py \
  --assets <skill_path>/assets \
  --data <JSON 경로> \
  --output "C:\Users\이더컴퍼니\Downloads\적재리스트_<발주번호>.pdf"
```

### 4단계: 경고 및 엣지 케이스 사용자에게 알리기

파서 실행 결과에 포함된 항목들 사용자에게 전달:
- `pallet_count` 팔레트수 불일치
- 박스번호 포맷 이슈 (아래 엣지 케이스 참고)
- 동봉 수량 vs 엑셀 수량 불일치

```json
{
  "company_name": "마인플로",
  "company_code": "A01359901",
  "order_id": "129673853",

    {

```

## 엣지 케이스 / 메모리

### 풀컨테이너를 여러 입고건으로 분할하는 경우
CN인사이더에서 풀컨테이너(예: 378박스)를 여러 쿠팡 입고건으로 나누는 경우가 있음. 이때 **이번 버전 스킬은 팔레트 단위로 박스번호를 재계산**하므로 문제없음 (기존 전역 번호 방식은 폐기됨).

### 엑셀 1행 박스수량 ≠ 동봉 팔레트별 박스합
엑셀 1행의 "박스수량:N"이 컨테이너 전체 박스수일 수 있음. 참고용이고, 실제 박스번호는 파싱된 팔레트별 박스수로 계산.

### 수량 불일치
CN 엑셀 SKU 합계가 동봉 발주수량과 다를 수 있음 (한 컨테이너에 여러 쿠팡 발주 섞임). 정상적인 상황이니 경고만 표시.
