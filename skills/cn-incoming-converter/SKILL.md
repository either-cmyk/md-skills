# CN출고내역 → 에이투지 간편입고 변환

CN인사이더에서 받은 출고내역 엑셀을 에이투지(사방넷 풀필먼트) 간편입고 등록 양식으로 변환한다.

## 입력 파일

사용자가 2개 파일을 제공해야 한다:

1. **출고내역 엑셀** (필수) - 파일명에 `S-QED` 또는 `출고내역` 포함
   - 1행: 타이틀 (머지셀, 박스수량 정보 포함)
   - 2행: 헤더 (B:상자번호, F:SKU, H:라벨명, K:출고수량, L:세트수량)
   - 3행~: 데이터
   - 마지막행: TOTAL

2. **공산품 상품코드 엑셀** (필수) - 파일명에 `공산품` 또는 `상품코드` 포함
   - C열: 상품코드, D열: 출고상품명, F열: 바코드
   - 바코드로 출고내역 SKU(F열)와 매핑

사용자가 공산품 상품코드 파일을 안 올렸으면 요청할 것.

## 변환 규칙

### 수량 결정
- L열(세트수량)이 있고 0보다 크면 → L열 사용
- L열이 없거나 0이면 → K열(출고수량) 사용

### 상품 그룹핑
- 바코드(SKU) 기준으로 동일 상품을 하나의 행으로 합산
- 수량은 전체 합계

### 박스번호 표기
- 원본 상자번호(S-QED-N-001 등) 그대로 유지
- 연속 박스는 `~`로 범위 표기: `S-QED-N-001~S-QED-N-003`
- 불연속 박스는 `,`로 구분: `S-QED-N-003, S-QED-N-005`
- 혼합: `S-QED-N-001~S-QED-N-003, S-QED-N-005`

### 정렬
- 라벨명(H열) 오름차순

### 상품코드 매핑
- 출고내역 F열(SKU/바코드) → 공산품 상품코드 F열(바코드) 매칭
- 매칭되면 공산품의 C열(상품코드), D열(출고상품명) 사용
- 매칭 안 되면 경고 출력하고 라벨명을 상품명으로 대체

## 출력 양식 (사방넷 간편입고 등록)

| 열 | 헤더 | 내용 |
|---|---|---|
| A | 박스넘버 | 박스번호 범위 |
| B | 출고상품코드 | 공산품 상품코드 |
| C | 상품명 | 출고상품명 |
| D | 수량 | 합산 수량 |
| E | 바코드 | SKU 바코드 |
| F | 유통기한 | 비워둠 |
| G | 로케이션 | 비워둠 |
| H | 입고메모 | 비워둠 |

## 실행

`scripts/convert.py` 스크립트를 사용하여 변환한다:

```bash
python scripts/convert.py <출고내역.xlsx> <공산품상품코드.xlsx> <출력파일.xlsx>
```

출력 파일명 규칙: `{S-QED코드}_{사업자명}_간편입고등록.xlsx`
- S-QED코드는 출고내역 1행 타이틀에서 추출
- 사업자명은 출고내역 파일명에서 추출

## 주의사항

- TOTAL 행은 제외할 것
- 머지셀이 있으므로 openpyxl로 읽을 때 cell.value로 접근 (MergedCell 처리 주의)
- 출력 시트명은 `엑셀입고`로 설정
- 폰트는 맑은 고딕 10pt, 헤더는 볼드
- 변환 후 총 수량이 원본 합계와 일치하는지 반드시 검증
