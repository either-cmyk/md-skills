# 노션 입고일지 자동 입력 스킬

쿠팡 거래명세서(물류동봉문서) PDF에서 정보를 추출하여 노션 입고일지 DB에 한 줄을 자동 생성한다.

## 노션 DB 정보

- **데이터소스 ID**: `d3406244-07e8-47d8-adc1-27018b053d95`
- **담당자 김현기 user ID**: `2cdd872b-594c-819a-9f78-0002fc5760a0`

## PDF에서 추출할 항목

거래명세서 PDF는 보통 "쿠팡 제출용"과 "업체 보관용" 2부가 들어있다. **쿠팡 제출용(1~2페이지)만 읽으면 된다.**

| PDF 항목 | 위치 |
|----------|------|
| 업체명 | 1.거래처정보 → 업체명 |
| 납품 센터 | 2.발주정보 → 납품 센터 (예: "인천4(INC4)") |
| 물류센터 도착예정일 | 2.발주정보 → 물류센터 도착예정일 (예: "20260414") |
| 운송타입 | 2.발주정보 → 운송타입 (예: "밀크런") |
| 팔레트수량 | 2.발주정보 → 팔레트수량 |
| 상품 목록 | 3.상품 정보 테이블 → 상품명/옵션, 발주수량 |

## 노션 DB 매핑 규칙

### 제목 (특이사항(센터, 입고상품))
센터 약칭 + 주요 상품명을 간결하게 조합한다. 기존 항목 스타일을 따른다.

**패턴**: `{센터약칭} {상품1} {상품2} ... {총수량}건`

예시:
- "인천4 슬라이드 운동화 선글라스 1310건"
- "고양1 빗자루 노깔 운동화"
- "이천2 운동화 축구화 164건"

센터약칭은 PDF의 납품센터에서 추출한다:
- "인천4(INC4)" → "인천4"
- "고양1(GYG1)" → "고양1"
- "이천2(ICN2)" → "이천2"
- 괄호 앞의 한글 부분만 사용

상품명은 상품 목록에서 **대표 카테고리명**만 뽑는다. 개별 옵션(색상, 사이즈)은 생략한다:
- "이더커머스 여성 가벼운 발편한 런닝화 운동화 / 핑크 225" → "운동화"
- "가드웰 무소음 AB 슬라이드 + 무릎패드 / 레드" → "슬라이드"
- "이더커머스 자외선차단 남녀공용 패션 선글라스+케이스 / Free 블랙" → "선글라스"

### 입고날짜
물류센터 도착예정일을 ISO-8601 날짜로 변환한다.
- "20260414" → "2026-04-14"

### 사업 계정 (multi_select)
업체명으로 판단한다. JSON 배열 형식으로 입력:
- 주식회사 이더컴퍼니 → `["이더컴퍼니"]`
- 클린인테크 → `["클린인테크"]`
- 마인플로 → `["마인플로"]`
- 이든코퍼레이션 → `["이든코퍼레이션"]`
- 뉴트리정 → `["뉴트리정"]`

하나의 PDF에 여러 사업자 상품이 섞여있을 수 있다. 그 경우 복수 선택한다.

### 보관위치 (select)
운송타입으로 판단한다:
- 밀크런, FBC → "CN FBC창고"
- 봄로지스 관련 → "봄로지스"
- 에이투지 관련 → "에이투지"
- 기본값: "CN FBC창고" (대부분 쿠팡 입고는 CN FBC창고)

### 파레트 수 / 파렛수(박스수)
팔레트수량을 두 필드 모두에 동일하게 입력한다.

### 담당자
항상 김현기로 설정: `["2cdd872b-594c-819a-9f78-0002fc5760a0"]`

### 상태
항상 "대기"로 설정.

## 실행 순서

1. 사용자가 PDF를 업로드하면 내용을 읽는다 (1~2페이지만)
2. 위 매핑 규칙에 따라 각 필드를 추출/변환한다
3. `notion-create-pages` 도구로 입고일지 DB에 페이지를 생성한다:

```
parent: { data_source_id: "d3406244-07e8-47d8-adc1-27018b053d95" }
properties: {
  "특이사항(센터, 입고상품)": "{제목}",
  "date:입고날짜:start": "{YYYY-MM-DD}",
  "date:입고날짜:end": null,
  "date:입고날짜:is_datetime": 0,
  "사업 계정": "[\"사업자명\"]",
  "보관위치": "{보관위치}",
  "파레트 수": {숫자},
  "파렛수(박스수)": {숫자},
  "담당자": "[\"2cdd872b-594c-819a-9f78-0002fc5760a0\"]",
  "상태": "대기"
}
```

4. 입력 완료 후 사용자에게 결과를 간단히 알려준다:
   - 제목, 입고날짜, 사업계정, 파레트 수 정도만 확인용으로 표시

## 주의사항

- PDF가 여러 장이어도 쿠팡 제출용(앞부분)만 파싱하면 된다. "업체 보관용"은 동일 내용 반복이다.
- 상품 합계 수량은 PDF 마지막의 "합계" 행에서 가져온다.
- 센터명이 여러 개인 경우(복수 센터 납품)는 각각 별도 행으로 생성한다.
- 사용자가 PDF 없이 텍스트로 정보를 알려주는 경우에도 동일한 매핑 규칙을 적용한다.
