# 그로스 재고 DB 시트 검증 루틴

## 언제 수행하나

**원가 계산(N값, FBC+밀크런비) 완료 직후 반드시 수행**. 오늘 계산한 값과 시트에 이미 입력된 값이 다를 수 있어 불일치를 포착하지 않으면 원가 왜곡이 축적된다.

## 검증 대상

**(이든코퍼레이션) ★그로스 통합관리 시트_빅셀 → 그로스 재고 DB**
- 스프레드시트 ID: `1ow9OBUrjJYjtuANyGBRCCEqkktfUwwKVk8oyv6oypbY`
- 시트명: `그로스 재고 DB`

## 시트 열 구조

| 열 | 헤더 | 의미 |
|---|---|---|
| B | 등록상품명 | 상품명 |
| L | 원가(위안) | 낱개 단가 ¥ |
| M | 중중배송비 | 위안 |
| N | 부가서비스 | 위안 |

| **Q** | **FBC+밀크런비** | **검증 대상 2** |
| V | 색상,수량 | 옵션 |
| W | 옵션 | 세부 옵션 |

**데이터 범위**: 3행 ~ 약 69행 (향후 확장 가능)

## 검증 절차

### 1) 시트 접속
Chrome 브라우저에서 해당 시트 탭으로 이동. `tabs_context_mcp`로 기존 탭 확인 후, 없으면 새 탭으로 접속.

### 2) 데이터 조회
Google Sheets는 canvas로 렌더되어 DOM 직접 파싱이 어렵다. **Name Box + Formula Bar 방식**이 가장 안정적:

```javascript
function getCell(addr) {
  const nameBox = document.querySelector('#t-name-box');
  nameBox.focus();
  nameBox.value = addr;
  nameBox.dispatchEvent(new Event('input', {bubbles: true}));
  nameBox.dispatchEvent(new KeyboardEvent('keydown', {key:'Enter', keyCode:13, which:13, bubbles:true}));
  return (document.querySelector('#t-formula-bar-input')?.innerText || '').trim();
}
```

계산 대상 상품군의 행 범위에서 V, W, L, P, Q 열 값을 배치(10~20행씩)로 스캔.

### 3) 계산 범위 자동 파악
방금 계산한 상품군의 B열(상품명) 매칭 행 찾기:
- 수세미 → B열 "스크래치 제로 양면 스펀지 수세미"
- 슬리퍼 → B열 "층간소음 EVA 거실화 슬리퍼"
- 목베개 → B열 "여행용 U자 메모리폼 목베개"
- 샤워기 → B열 "3단 조절 수압상승 필터 샤워기"
- 캐리어커버 → B열 "여행용 방수 캐리어 보호 커버"

### 4) 대조 기준

| 열 | 오차 허용 |
|---|---|
| P (위안당 원화) | ±1원 (소수점 반올림 감안) |
| Q (FBC+밀크런비) | 정확 일치 (1원 단위) |

### 5) 결과 리포트

불일치 항목만 표로 정리. 전체 일치 항목은 건수만 표시.

```
## 그로스 재고 DB 검증 결과

### ✅ 일치 (수정 불필요)
| 상품 | 행 범위 | 건수 | P값 | Q값 |
| ... | ... | ... | ... | ... |

### ❌ 불일치 (수정 검토 필요)
| 행 | 상품 | 옵션 | 시트 P | 기대 P | 차이 | 시트 Q | 기대 Q |
| ... | ... | ... | ... | ... | ... | ... | ... |

**총 N건 · 일치 X건 · 불일치 Y건**
```

## 중요 규칙

### ⚠️ 수정 금지 (기본)
**Claude는 시트를 수정하지 않는다**. 불일치만 리포트. 사용자가 명시적으로 "수정해줘"라고 지시한 경우에만 수정.

### ⚠️ 사유 분석
불일치가 있으면 원인 추정:
- 시트 값이 이전 계산(25.12.01) 기준이라 옛 값일 수 있음
- 단가 변경이 반영 안 됨
- 옵션 누락

## 실전 예시 (2026-04-23)

**65건 중 4건 P열 불일치 발견**:

| 행 | 상품 | 시트 P | 기대 P | 차이 |
|---|---|---|---|---|
| 3 | 수세미 12개입 | 312 | 362 | +50 |
| 4 | 수세미 20개입 | 320 | 365 | +45 |
| 54 | 샤워기 1개 | 318 | 286 | −32 |
| 55 | 샤워기 2개 | 318 | 286 | −32 |

Q열은 65건 모두 정확. 사용자에게 차이만 알리고 현 상태 유지.

## 트리거 시점

아래 경우 자동 실행:
1. 위안당 원화(N) 계산 완료 후
2. FBC+밀크런비 계산 완료 후
3. 기존 상품 단가·박스당 입수량 변경 시
4. 사용자가 "시트 검증" / "값 확인" 요청 시
