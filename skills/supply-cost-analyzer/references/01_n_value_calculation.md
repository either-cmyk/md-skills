# 위안당 원화 (N값) 상세 계산법

## 정의

**N값 = "상품 1위안이 통관 완료 상태로 한국 창고에 도착했을 때의 총 원화 비용"**

중국 내 발생 비용 + 한국 통관 관련 비용을 모두 합쳐 위안화 상품가로 나눈 값. 즉 "1위안짜리 상품을 한국에 통관까지 들여오는 데 총 얼마가 드는가"를 나타낸다.

## 공식

```
C (¥) = 상품금액 + 중중배송비(운임) + 부가서비스 + 포장비용     [수수료 제외]
D (¥) = 수수료 (CN 기본 수수료)
F (₩) = 청구서 TOTAL (DOF·COC·관세·부가세·통관수수료·구매대행 다 포함)
        혼적이면 CBM 비중으로 상품별 배분

M = (C + D) × 220 + F       ← 환율 220 고정 (하드코딩, 실시간 환율 아님)
N = M ÷ C
```

## 계산 순서

### 1) CN 내주문에서 CNY 확보
- `https://www.cninsider.co.kr/mall/` → 내주문
- 해당 발주번호 검색 → 상세 페이지
- **두 섹션 모두** 확인:
  - 발주금액: 상품금액, 물류비, 수수료, 부가서비스
  - 출고금액: **포장비용** ← 자주 놓침
- 할인이 있으면 결제금액 기준 비례 축소

### 2) 청구서 TOTAL 확보
- Gmail `kimhh0522@gmail.com`의 "청구서 + 팡빌" 라벨에서 해당 B/L 청구서 찾기
- `TOTAL` 칸의 KRW 합계 → F값
- 세부 내역(DOF/COC/관세/부가세/통관수수료/구매대행수수료) 분리 불필요. **TOTAL 통째로**

### 3) 혼적 여부 판단
- 단일 상품이면 F 전체가 해당 상품 F
- 혼적이면 **CBM 비중**으로 배분:
  ```
  F_상품 = 청구서 TOTAL × (상품 CBM ÷ 전체 CBM)
  ```
- CBM은 CN 출고내역 박스 popover에서 확인

### 4) 부분출고 처리 (우선 적용)
실제 출고수량 / 발주수량 비율로 모든 CNY 항목 축소:
```
출고 비율 = 실제 출고 / 발주
조정된 C = C × 출고 비율
조정된 D = D × 출고 비율
```
- 할인은 이미 부분출고분에 반영된 것으로 간주 (별도 비례 배분 불필요)

### 5) N값 계산
```
M = (C + D) × 220 + F
N = M ÷ C
```

## 계산 예시

### 예시 1: 단일 상품 완전 출고 (S-QEC260410 캐리어커버)
```
CN 내주문:
  상품금액    ¥3,306.00
  수수료       ¥231.42
  포장비용     ¥287.50     ← 출고금액 섹션에서 확인!
  부가서비스    ¥0.00

C = 3,306 + 0(운임) + 0(부가) + 287.50(포장) = ¥3,593.50
D = ¥231.42
F = ₩248,322   (단일 상품이라 전체)

M = (3,593.50 + 231.42) × 220 + 248,322 = ₩1,089,804
N = 1,089,804 ÷ 3,593.50 = ₩303.27
```

### 예시 2: 혼적 완전 출고 (S-QEC260401 샤워기+필터)
```
CN 내주문 S-QEC2603252:
  상품금액 ¥26,600 / 운임 ¥600 / 수수료 ¥1,904 / 부가 ¥1,200 / 할인 -¥240

완전 출고 → 결제금액/발주금액 비율로 비례 축소
  비율 = 30,064 / 30,304 = 0.9921
  C = (26,600 + 600 + 1,200) × 0.9921 = ¥28,175
  D = 1,904 × 0.9921 = ¥1,889

청구서 TOTAL = ₩1,568,999
샤워기 CBM 비중 = 6.076 / 6.64 = 91.51%
F_샤워기 = 1,568,999 × 0.9151 = ₩1,435,769

M = (28,175 + 1,889) × 220 + 1,435,769 = ₩8,049,849
N = 8,049,849 ÷ 28,175 = ₩285.72
```

### 예시 3: 부분출고 (S-QEC260413 목베개)
```
CN 내주문 S-QEC260325:
  상품금액 ¥17,220 / 수수료 ¥1,205.40 / 부가서비스 ¥1,120 / 할인 -¥224
  발주 1,400개 → 실제 출고 1,395개

출고 비율 = 1,395 / 1,400 = 0.99643

C = (17,220 × 0.99643) + (1,120 × 0.99643) = 17,158.50 + 1,116.00 = ¥18,274.50
D = 1,205.40 × 0.99643 = ¥1,201.10

청구서 TOTAL = ₩1,582,139   (단일 상품, 전체 사용)

M = (18,274.50 + 1,201.10) × 220 + 1,582,139 = ₩5,866,771
N = 5,866,771 ÷ 18,274.50 = ₩321.04
```

## N값 실측 범위 (이든코퍼레이션 밀크런 파레트 기준)

| 상품군 | N값 | 특징 |
|---|---|---|
| 수세미 | ₩362~365 | 단가 낮고 부피 커서 N 최고 |
| 슬리퍼 | ₩346~349 | 단가 낮고 부피 큼 |
| 목베개 | ₩321 | 단가 중간·부피 큼 |
| 캐리어커버 | ₩303 | 단가 중간·박스당 많이 담김 (N 최저) |
| 샤워기+필터 | ₩286 | 단가 높고 박스당 적게 |

일반 범위: **₩340~370**. ₩310 미만 또는 ₩400 초과면 계산 실수 가능성 → 재검토.

## N값 결정 원리 (직관적 이해)

```
N값 ≈ 220(환율) + (통관 원화 배분액 ÷ 위안화 합계)
```

- 박스당 위안화 가치가 낮을수록 → 통관비를 작은 ¥로 나눠야 함 → **N 높음**
- 박스당 위안화 가치가 높을수록 → 통관비를 큰 ¥로 나눔 → **N 낮음**

예: 수세미 박스당 ¥96 vs 캐리어커버 박스당 ¥661 → 수세미 N이 캐리어커버보다 높음.

## 이중 확인 원칙

**발주서(CN 내주문) + 출고내역(CN B/L) 반드시 교차 검증**:

| 확인 항목 | 발주서 | 출고내역 |
|---|---|---|
| 상품금액·수수료·부가·포장 | ✓ | |
| 실제 출고 수량 | | ✓ |
| 박스별 SKU 구성 | | ✓ |
| 박스당 입수량 | | ✓ (popover) |
| CBM | | ✓ |

교차 검증 포인트:
1. 발주 수량 vs 실제 출고 수량 (부분출고 체크)
2. 발주 단가 × 출고 수량 = 박스별 popover 상품금액 합 (일치해야 함)
3. 박스 popover 수량이 "낱개" 기준인지 "세트" 기준인지 판단
