# FBC + 밀크런비 상세 계산법

## 개념

한국 내 물류비로, **N값 영역 바깥**에 있다. 통관 완료 이후 쿠팡 센터까지 도달시키는 비용이다.

- **FBC**: 한국 CN 센터 작업비 (상품 수령·분류·파레트 적재)
- **밀크런**: 쿠팡 센터 배송비 (파레트 단위 직납)

## 고정 단가 (2026-04 기준)

```
FBC:    ₩35,000 / 파레트
밀크런: ₩25,800 / 파레트   [인천14 기준, 인천 출고지 최저가]
합계:   ₩60,800 / 파레트
```

### 쿠팡 센터별 밀크런 단가

인천14 외 센터는 `밀크런_파레트별_최적배차.html` 참조. 인천 출고지 기준:
- **인천14/16/26/28/30/32/33/36/42/45**: ₩25,800 (최저)
- **동탄1**: ₩38,500
- **평택1**: ₩40,300
- **대구**: ₩56,000

## 파레트당 박스 수 (상품군별 고정)

| 상품군 | 박스 규격 | 파레트 박스수 |
|---|---|---|
| 캐리어커버 | 50×40×30 | **22박스/파레트** |
| 그 외 상품 | 57×45×37 | **16박스/파레트** |

## 박스당 비용 (선계산)

```
캐리어커버: 60,800 ÷ 22 = ₩2,764/박스
기타 상품:  60,800 ÷ 16 = ₩3,800/박스
```

## 개당 FBC+밀크런 (핵심)

```
SKU 개당 FBC+밀크런 = 박스당 비용 ÷ 그 SKU의 박스당 입수량
```

### 왜 SKU별로 다른가?

같은 상품이어도 사이즈·옵션별로 박스당 입수량이 다름:
- 캐리어커버 18인치: 박스당 65세트 → 개당 ₩43
- 캐리어커버 30인치: 박스당 30세트 → 개당 ₩92

실제 차지하는 공간 비율대로 비용 부담 → **자동으로 공평**.

## 계산 예시

### 캐리어커버 18인치 (박스당 65세트)
```
개당 FBC+밀크런 = 2,764 ÷ 65 = ₩42.52 ≈ ₩43/세트
```

### 수세미 12개입 (박스당 24봉)
```
개당 FBC+밀크런 = 3,800 ÷ 24 = ₩158.33 ≈ ₩158/봉
```

### 슬리퍼 1켤레 240-245 (박스당 50켤레)
```
개당 FBC+밀크런 = 3,800 ÷ 50 = ₩76/켤레
```

## 합쳐서 계산 vs 각각 계산 (결과 동일)

분배 법칙 성립:
```
(35,000 + 25,800) ÷ 개수 = 35,000 ÷ 개수 + 25,800 ÷ 개수
```
→ **합쳐서 ₩60,800 ÷ 개수로 계산 권장** (간편하고 결과 동일)

## 1+1 세트 옵션 처리

CN 시스템 수량은 항상 "낱개" 기준. 세트 옵션은 변환:
```
1+1 박스당 세트 = 1켤레 박스당 켤레 ÷ 2 (내림)
FBC+밀크런/세트 = 박스당 비용 ÷ 세트 수
```

예) 슬리퍼 240-245 1+1:
- 1켤레 박스당 50켤레 → 1+1 박스당 25세트
- 3,800 ÷ 25 = ₩152/세트

## 결과 보고 포맷

원가 계산 결과 공유 시 아래 4가지 포함:

1. **N값 (위안당 원화)**: 중국 비용까지의 환산 계수
2. **단위당 CN+통관 원가**: 단가(¥) × N
3. **단위당 FBC+밀크런**: 박스당 비용 ÷ 박스당 입수
4. **최종 공급원가**: (2) + (3)

```
| 옵션 | 단가(¥) | N | CN+통관(₩) | FBC+밀크런(₩) | 공급원가(₩) |
```

## 주의

### ⚠️ 박스 규격 확인
박스 규격이 같아 보여도 CN에서 다른 상품 섞이면 규격 다를 수 있음. 출고내역 박스별 popover에서 사이즈/중량 확인.

### ⚠️ 다른 쿠팡 센터 사용 시
- `밀크런_파레트별_최적배차.html` 확인
- 파레트 단가 변경: 밀크런 ₩25,800 → 해당 센터 단가
- 박스당 비용 재계산

### ⚠️ 파레트당 박스수는 고정값
실제 적재량이 아닌 **계약 기준 고정값**. 실적 편차 발생해도 계산에는 고정값 사용.
