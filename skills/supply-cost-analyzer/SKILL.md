# 이든코퍼레이션 SKU별 공급원가 계산

이 스킬은 **상품 1개당 공급원가**를 산정하는 전체 워크플로우다. 세 가지 핵심 비용을 순차 계산하고 구글시트와 대조 검증까지 수행한다.

## 원가 구조 (반드시 먼저 이해할 것)

```
┌────────── 중국 비용 (위안당 원화 = N값 영역) ──────────┬── 국내 물류 ──┬── 판매 비용 ──┐
│  중국 내:  상품가 + 중중배송비 + 부가서비스 + 포장비   │              │              │
│  통관:     중한배송비 + 관세 + 부가세 + 통관수수료     │  FBC + 밀크런 │ 쿠팡수수료   │
│                                                         │              │ 입출고·배송  │
└────────────────────────────────────────────────────────┴──────────────┴──────────────┘
   시트 L~O열 (위안) → P열 (위안당 원화 환산)             Q열            R,S,T열

공급원가 = (단가¥ × N) + FBC+밀크런/단위
```

**핵심 개념**: "중국 비용"은 중국 내 발생 + 한국 통관 완료까지 모든 비용을 포함한다. 그 위안당 원화 환산 계수가 **N값**이다. FBC+밀크런비는 통관 이후 국내 물류비로 **N값 바깥**에 있다.

## 필수 공식 (암기 권장)

### N값 (1위안당 원화)
```
C = 상품금액(¥) + 중중배송비(¥) + 부가서비스(¥) + 포장비용(¥)   [수수료 제외]
D = 수수료 (¥)
F = 청구서 TOTAL (₩, 혼적 시 CBM 비중 배분)
M = (C + D) × 220 + F                     ← 환율 220 고정
N = M ÷ C                                  ← 위안당 원화
```

### FBC + 밀크런 개당 비용
```
파레트 비용 = FBC(35,000) + 밀크런(25,800) = ₩60,800/파레트   [인천14 기준]

박스당 비용:
  캐리어커버 (50×40×30, 파레트 22박스):  60,800 ÷ 22 = ₩2,764/박스
  기타 상품 (57×45×37, 파레트 16박스):  60,800 ÷ 16 = ₩3,800/박스

개당 비용 = 박스당 비용 ÷ 박스당 입수량
```

### 최종 공급원가
```
공급원가/단위 = (단가¥ × N) + FBC+밀크런/단위
```

## 자주 놓치는 포인트 (경고)

### ⚠️ 포장비용
CN 내주문 상세페이지에서 **발주금액**과 **출고금액** 두 섹션 모두 확인. 부가서비스가 ¥0이어도 "포장비용"이 별도로 있을 수 있어 C가 과소 계상될 수 있다.

### ⚠️ 세트 vs 낱개
CN 시스템 수량은 항상 **낱개(개/켤레) 기준**. 1+1 세트 옵션이면 박스당 입수량은 `÷ 2` 후 내림.

### ⚠️ 박스당 입수량 = "실측 + 예측"
첫 발주는 박스가 가득 안 찬 경우가 많아 관찰값이 박스 한계가 아닐 수 있다. 관찰값이 이론 75% 부피값보다 낮으면 "박스 한계 미확인"으로 보고 **이론 90%**를 예측값으로 사용한다. 상세는 `03_box_capacity_rules.md`.

### ⚠️ 관세 vs 부가세
관세는 품목별로 다름(FTA 0~13%), 부가세는 일괄 10%. **N값의 주요 결정 요인은 관세가 아니라 "박스당 위안화 가치"**다. 단가가 낮거나 입수량이 적으면 박스당 ¥ 값이 낮아져 N값이 올라간다.
