# 쿠팡 입고 직송 (동봉문서 PDF → 사방넷 발주등록)

## 개요

쿠팡 입고(로켓발주/밀크런) 건은 별도 택배 발송이 아니라 쿠팡 센터로 **직송**한다.
사용자가 쿠팡 물류동봉문서(거래명세서) PDF를 올리면, 사방넷 발주등록 양식(23컬럼,
시트명 `발주등록_sample`)으로 변환하여 **직송** 발주 엑셀을 만든다.
사용자가 직접 사방넷풀필먼트에 업로드한다.

- **실배송 = 택배** (real-shipping 스킬) / **동봉문서 = 쿠팡 입고 = 직송** (이 스킬)

## 사방넷 계정 / 사업자 판별

PDF의 **업체명** 필드로 계정을 판별한다.

| 업체명 | 사방넷 계정 | 코드 접두사 | 매핑 방식 |
|--------|-------------|-------------|-----------|
| 뉴트리정 | 뉴트리정 | N | 번들 SKU표 + 1개입 품목 키워드 (스킬 내장) |
| 그 외(이더컴퍼니 등) | 이더컴퍼니 | E | 공산품 상품코드 엑셀(바코드→코드) 필요 |

## 입력

- **필수:** 쿠팡 물류동봉문서 PDF (`물류동봉문서_YYYYMMDD_HHMMSS.pdf`). 여러 개 동시 가능.
- **(공산품일 때만) 공산품 상품코드 엑셀**: C열=상품코드, D열=출고상품명, F열=바코드.
  이더컴퍼니 동봉문서인데 이 파일이 없으면 사용자에게 요청한다.

## 실행 방법

```bash
python3 <skill-path>/scripts/convert.py <물류동봉문서.pdf> [<...추가 PDF>] \
  [--goods <공산품상품코드.xlsx>] \
  --outdir "<사용자 선택 폴더(예: 김현기)>"
```

출력 파일명: `사방넷_{계정}_직송_{YYYYMMDD}_{발주번호}.xlsx` (계정별 1개씩)

## 변환 규칙 (실배송과 다른 점)

| 컬럼 | 실배송(택배) | 직송(쿠팡입고) |
|------|--------------|----------------|
| 배송방식 | `택배` | **`직송`** |
| 발주 타입 | (빈칸) | **`쿠팡 - 파렛트출고`** |
| 출고희망일 | (빈칸) | **PDF "물류센터 도착예정일"** (예: `20260602`) |
| 상품고유코드 | N/E 매핑 | 아래 매핑 규칙 |

### 나머지 필드
- 수량: PDF 확정수량(없으면 발주수량) 그대로
- 판매상품명: PDF 상품명/옵션
- 받는분 이름: PDF 납품센터명 (예: `전라광주2(GWJ2)`)
- 주소1: PDF 납품센터주소
- 주문번호 / 전화번호 / 우편번호 / 관리메모: **비워둠**

## 상품 매핑 규칙

### 뉴트리정 (N계정) — `scripts/mapping_rules.json` 내장
**판매상품명은 반드시 사방넷 등록명(sku_master)을 사용한다. PDF 원문 상품명은 fallback.**
1. PDF **상품번호**가 `sku_master`(사방넷 판매상품 마스터, 139개)에 있으면
   → 그 코드 + 마스터의 판매상품명 그대로 사용. (번들 2~6개입 + 신상품군 1개입 8자리 포함)
2. 없으면 1개입 → **상품명 키워드**로 품목을 인식해 1개입 `N00200xxx` 코드 + 마스터 명칭 사용.
   - 공백 제거 후 매칭(PDF 줄바꿈으로 단어가 쪼개질 수 있음). 멜라토닌은 `2mg`/`5mg` 구분.
   - 예: `68886411`(마스터에 없음) + "콜린 미오이노시톨" → `N00200006` "[뉴트리정] 뉴트리정 리얼콜린미오이노시톨4000 [2.5g*60P]".
3. 둘 다 실패 → `???` + 검수 보고.
- 마스터 갱신: 사방넷 판매상품 엑셀(`판매상품_YYYY-MM-DD_*.xlsx`, A열=상품코드/D열=판매상품명)을
  받아 `sku_master`를 통째로 교체.

### 이더컴퍼니 (E계정) — 공산품 상품코드 엑셀
- PDF **상품 바코드(13자리)** → 공산품 엑셀 F열(바코드) 매칭 → C열(상품코드) + D열(출고상품명) 사용.
- 파일 없거나 미발견 → `???` + 검수 보고.

## 검수 / 주의사항
- 시트명은 반드시 `발주등록_sample`.
- 매핑 실패(`???`)는 변환을 막지 않고, 완료 후 "검수 필요" 항목으로 사용자에게 보고한다.
- 출고희망일/상품고유코드/우편번호/전화번호는 문자열(앞자리 0·날짜 보존).
- **사방넷에 직접 업로드하지 않는다.** 엑셀만 생성하고 사용자가 업로드.
- 출력은 사용자 선택 폴더(`김현기`)에 저장해 바로 열 수 있게 한다.

## 룰 데이터 업데이트
- 뉴트리정 신규 품목/번들 추가 시 `scripts/mapping_rules.json`의
  `bundle_skus`(번들 코드)·`onepack_rules`(1개입 키워드/코드)를 갱신한다.
