# CN인사이더 발주 자동화

## 개요

이 스킬은 2단계로 동작한다:

1. **체크 단계**: 4개 사업자의 구글시트 재고 DB를 읽어 발주 필요 상품을 분석하고 리포트 제공
2. **실행 단계**: 사용자가 선택한 사업자의 상품을 CN인사이더에서 검색하여 장바구니에 담기

사용자가 "발주 체크해줘"라고 하면 1단계만 실행하고, "이더컴퍼니 발주해줘"라고 하면 1→2단계를 연속 실행한다.

## 핵심 원칙: 수량은 널널하게

이 회사는 발주 수량을 타이트하게 맞추기보다 **여유롭게 잡는 것을 선호**한다. 원가가 저렴한 상품이 대부분이라 과소 발주로 품절이 나는 것이 과다 발주보다 훨씬 큰 리스크다. 발주 공식 결과가 애매할 때는 항상 넉넉한 쪽으로 올림하고, 사용자가 "좀 더 올려도 돼"라고 하면 주저하지 않고 반영한다.

헤더는 1~2행이고, 데이터는 3행부터 시작한다.

### 열 위치 자동 감지 (중요)

시트 구조가 바뀔 수 있으므로 열 위치를 하드코딩하지 않는다. 시트를 읽을 때 **헤더 행(2행)의 텍스트를 기준으로 열 위치를 동적으로 파악**한다:

1. 2행의 모든 셀을 읽는다
2. 키워드로 열을 식별한다:
   - "등록상품ID" → A열
   - "등록상품명" → B열
   - "SKU" → F열
   - "색상" → V열
   - "옵션" → W열
   - "7일" → X열 (최근 7일 판매량)
   - "15일" → Y열 (최근 15일 판매량)
   - "30일" → Z열 (최근 30일 판매량)
   - "쿠팡 재고" or "구팡재고" → AA열
   - "에이투지" or "비이투지" → AB열
   - "입고 예정" → AC열
   - "납기" → AD열
3. 키워드 매칭 실패 시 기본 알파벳 위치(위 표)를 폴백으로 사용

## 시트 읽기 방법

### gviz/tq 엔드포인트 (권장)

Chrome 브라우저에서 시트를 직접 스크롤하며 읽는 것보다, gviz/tq 엔드포인트로 CSV 데이터를 가져오는 것이 훨씬 효율적이다.

```
https://docs.google.com/spreadsheets/d/{SHEET_ID}/gviz/tq?tqx=out:csv&gid=0
```

이 URL을 Chrome 탭에서 열면 CSV 형태로 전체 데이터를 볼 수 있다. `read_page`나 `get_page_text`로 읽는다.

### gviz 엔드포인트 주의사항

1. **빈 행 스킵**: gviz는 빈 행을 건너뛰기 때문에 행 번호가 실제 시트와 맞지 않을 수 있다. 따라서 **행 번호 기반이 아닌, 등록상품ID(A열) 기반으로 상품을 식별**해야 한다.
2. **레이트리밋**: 짧은 시간에 여러 번 요청하면 빈 200 응답이 올 수 있다. 이 경우 잠시 대기 후 재시도하거나, Chrome에서 시트를 직접 열어 읽는 방식으로 전환한다.
3. **대용량 시트**: 이더컴퍼니(~1132행)처럼 큰 시트는 한 번에 읽으면 데이터가 잘릴 수 있다. 필요한 열만 tq 쿼리로 필터링하거나, 여러 번 나눠 읽는다.

### 특정 상품만 읽기

특정 상품만 확인할 때는 tq 쿼리로 등록상품ID를 필터링한다:
```
&tq=SELECT * WHERE A = '14774981947'
```

### 대안: Chrome에서 직접 읽기

gviz가 안 될 때의 폴백:
1. 시트를 Chrome에서 연다: `https://docs.google.com/spreadsheets/d/{SHEET_ID}/edit?gid=0#gid=0`
2. Name Box에 셀 주소를 입력하여 필요한 영역으로 이동
3. 스크린샷과 zoom으로 데이터를 읽는다

## STEP 1: 발주 필요량 분석

### 가중평균 일일판매량

7일 판매량만 사용하면 프로모션이나 일시적 수요 변동에 발주량이 크게 흔들린다. 이를 안정화하기 위해 7일/15일/30일 판매량을 가중평균하여 **안정적인 일일판매량**을 산출한다:

```
가중판매량 = (X × 0.5) + (Y × 0.3) + (Z × 0.2)
일평균 = 가중판매량 ÷ 7
```

- `X`: 최근 7일 판매량 (가중치 50% — 최신 트렌드 반영)
- `Y`: 최근 15일 판매량 (가중치 30% — 중기 안정성)
- `Z`: 최근 30일 판매량 (가중치 20% — 장기 기저 수요)

이렇게 하면 한 주 반짝 판매가 튀어도 15일/30일 데이터가 완충 역할을 하고, 반대로 일시적으로 빠져도 과소 발주를 방지한다.

**Y나 Z가 비어있는 경우**: 신상품 등 데이터가 부족하면 있는 데이터만으로 가중치를 재분배한다. 예: Y만 없으면 `(X × 0.7) + (Z × 0.3)`, X만 있으면 `X` 그대로 사용.

### 발주 공식

```
발주필요량 = ROUNDUP( (일평균 × 38.5) + (일평균 × AD) - AA - AB - AC , -1)
```

각 변수의 의미:
- `일평균 × 38.5`: **5.5주치** 목표 재고 (일평균 × 38.5일)
- `일평균 × AD`: 납기일 동안 소진될 예상 수량 (일평균 × 납기일수)
- `AA`: 쿠팡에 현재 있는 재고
- `AB`: 에이투지(비이투지)에 있는 재고
- `AC`: 이미 발주한 수량 합계 (AE~AK의 합)
- `ROUNDUP(..., -1)`: **10단위 올림** (예: 123 → 130, 201 → 210)

**발주필요량이 0 이하이면 발주 불필요**, 양수이면 해당 수량만큼 발주 필요.

### 5.5주치를 쓰는 이유

시트에 내장된 자동발주 수식은 30일(~4.3주) 판매량을 기준으로 하는데, 품절 기간이 포함되어 실제 수요보다 과소 추정되는 문제가 있다. 가중평균 일평균이 최근 수요를 더 안정적으로 반영하며, 5.5주치는 넉넉하면서도 과다 재고가 되지 않는 균형점이다. 원가가 싼 상품이 대부분이라 넉넉하게 잡아도 리스크가 적다.

### 변동폭 경고 (±30% 이탈 감지)

발주량이 이전 발주 대비 크게 변동하면 리포트에 경고를 표시한다. 급격한 변동은 데이터 이상이나 일시적 수요 왜곡일 수 있으므로 사용자가 한 번 더 확인할 수 있게 돕는다.

**비교 기준**: AC열(기발주 합계)에 이미 발주한 수량이 있으므로, 이번 발주필요량과 AC값을 비교한다.

```
변동률 = (발주필요량 - AC) ÷ AC × 100
```

- **|변동률| > 30%** → 경고 표시
- AC가 0이면 (첫 발주) 경고 생략

리포트 표시 예시:
```
🔴 깔창 235-240 → 발주 310개 ⚠️ 이전 대비 +45% (기존 발주 210개)
🟡 선글라스 블랙 → 발주 200개 ⚠️ 이전 대비 -35% (기존 발주 310개)
```

변동폭 경고는 정보 제공용이지 발주를 막는 것이 아니다. 사용자가 "괜찮아, 진행해"라고 하면 그대로 진행한다.

### 수량 조정 원칙

- 공식 결과는 **출발점**이지 최종값이 아니다. 사용자가 조정을 원하면 유연하게 대응한다.
- 사용자가 "좀 더 올려도 될 것 같아"라고 하면 10~20% 올린 값을 제안한다.
- 원가가 특히 저렴한 상품(단가 ¥1 이하)은 더 널널하게 잡아도 괜찮다.
- 최종 수량은 항상 10단위로 올림한다.

### 긴급도 판단

재고가 며칠분 남았는지 계산하여 긴급도를 표시한다:

```
남은 일수 = (AA + AB) ÷ 일평균
```

- **긴급 (빨강)**: 남은 일수 < 7일 (1주 미만)
- **주의 (노랑)**: 남은 일수 < 14일 (2주 미만)
- **여유 (초록)**: 남은 일수 ≥ 14일

`일평균`은 위 "가중평균 일일판매량" 섹션에서 계산한 값을 사용한다.

### 특수 규칙 (이더컴퍼니 시트 전용)

- **등록상품ID 14774981947 (메인 깔창, 바디인솔 노랑깔창 OEM)**: 최우선 체크 대상. 이 상품은 메인 상품이므로 재고에 구멍이 나면 안 된다. 리포트 상단에 별도로 강조 표시하고, 발주필요량이 0 이하라도 여유가 적으면 주의 표시.
- **등록상품ID 14727705236 (다른 깔창)**: 완전 제외. 발주 체크도 하지 않는다.
- **뉴트리정 관련 상품**: 이 스킬에서는 아예 다루지 않음 (뉴트리정은 외부 발주)

### 리포트 출력 형식

체크 결과를 사업자별로 정리하되, **각 상품마다 계산 근거를 한 줄로 표시**하여 사용자가 수량의 타당성을 즉시 판단할 수 있게 한다:

```
📊 발주 체크 결과 (2026-04-07)

━━━ 이더컴퍼니 (eithercommerce) ━━━
⚠️ 메인 깔창 현황 (바디인솔 노랑깔창 OEM):
  🔴 225-230 → 120개 (일평균 12.0 × 38일분, 재고 200+50, 기발주 100) ⚠️ 이전 대비 +42%
  🔴 235-240 → 210개 (일평균 21.4 × 38일분, 재고 300+80, 기발주 150)
  ...

발주 필요 상품: 23개 (긴급 5개 / 주의 8개)
  🔴 상품명 / 옵션 → 50개 (일평균 3.2 × 38일, 재고 20+0, 기발주 0) 남은 6일
  🟡 상품명 / 옵션 → 20개 (일평균 1.5 × 38일, 재고 30+10, 기발주 0) 남은 12일
  ...
```

**한 줄 근거 형식**: `발주수량 (일평균 N.N × 38일분, 재고 AA+AB, 기발주 AC)`
- 일평균: 가중평균 일일판매량
- 38일분: 5.5주치 = 38.5일 (+ 납기일 AD일 포함)
- 재고: 쿠팡재고(AA) + 에이투지재고(AB)
- 기발주: AC열 값
- 변동폭 경고가 있으면 끝에 `⚠️ 이전 대비 ±N%` 추가

이 형식 덕분에 사용자가 "왜 이 수량이지?"라고 묻지 않고도 바로 판단할 수 있다.

리포트를 보여준 후, 사용자에게 어떤 사업자의 발주를 진행할지 물어본다.

## STEP 2: CN인사이더 장바구니 담기

사용자가 특정 사업자를 선택하면 CN인사이더에서 해당 상품들을 장바구니에 담는다.

### 로그인 플로우

CN인사이더(https://www.cninsider.co.kr/mall/#/)는 사업자별 계정이 별도이다.

1. CN인사이더 로그인 페이지로 이동
2. ID 입력란에 해당 사업자의 CN인사이더 ID를 입력
3. **비밀번호는 사용자가 직접 입력** — 보안 정책상 비밀번호 입력 불가
4. 캡챠(이미지/텍스트 인증) 읽어서 입력 — 텍스트 기반 캡챠이므로 읽기 가능
5. 로그인 버튼 클릭
6. 사용자에게 "비밀번호를 입력해주세요. 입력 완료되면 말씀해주세요." 안내

### 장바구니 담기 전 최종 확인 (중요!)

로그인 후, 실제로 장바구니에 담기 시작하기 **전에** 발주 대상 전체를 요약하여 사용자에게 최종 확인을 받는다:

```

━━━ 이더컴퍼니 (총 12개 옵션) ━━━
1. 바디인솔 노랑깔창 OEM

   - 235-240: 210개

   - 케이스: 300개

진행할까요? (수량 수정이 필요하면 말씀해주세요)
```

- 변동폭 경고(⚠️)가 있는 항목은 여기서도 표시
- 사용자가 **"진행해"** / **"OK"** / **"ㅇㅇ"** 등 명확히 확인해야 장바구니 담기 시작
- 수량 수정 요청이 있으면 반영 후 다시 확인
- 이 단계에서 특정 상품만 제외하거나 수량 조정도 가능

### 상품 검색 및 장바구니 담기

CN인사이더 상품리스트 페이지: `https://www.cninsider.co.kr/mall/#/favoriteList`

위 최종 확인에서 사용자가 승인한 항목들에 대해:

1. **상품 검색**: 상품리스트 페이지의 조회 필드에 시트 B열(등록상품명)을 입력하고 검색
2. **검색 실패시**: B열 대신 F열(SKU/바코드)로 재검색
3. **상품 클릭**: 검색된 상품을 클릭하여 상세 페이지로 이동
4. **옵션 매칭 (SKU 기반)**: 아래 "옵션 매칭 방법" 섹션 참고
5. **수량 입력**: 발주필요량을 수량 필드에 입력
6. **장바구니 추가**: "장바구니 추가" 버튼 클릭
7. 다음 상품으로 이동하여 반복

동일 상품의 다른 옵션들은 한 번의 상세 페이지 방문에서 모두 처리한다 (같은 등록상품ID를 가진 행들을 묶어서 처리).

### 옵션 매칭 방법: SKU 기반 매칭

CN인사이더의 옵션명은 중국어로 되어 있어서 시트의 한국어 옵션명과 직접 비교할 수 없다. 대신 **SKU(바코드)를 기준으로 매칭**한다.

1. CN인사이더 상품 상세 페이지에서 옵션을 하나씩 클릭한다
2. 옵션을 클릭하면 하단에 해당 옵션의 SKU(바코드)가 표시된다
3. 이 SKU를 시트의 F열(SKU)과 대조하여 올바른 옵션을 식별한다
4. SKU가 확인되면 해당 옵션의 체크박스를 체크하고 수량을 입력한다

### 연관 상품 규칙

일부 상품은 본 상품 외에 부속품도 함께 발주해야 한다:

- **선글라스 → 케이스**: 선글라스 총 수량(모든 색상 합계)만큼 "검은 안경 가방" 옵션의 케이스도 같이 발주한다. 예: 선글라스 500 + 50 + 50 = 600이면, 케이스도 600개.

### CN인사이더 UI 조작 순서 (중요!)

CN인사이더 상품 상세 페이지에서 옵션별 수량을 입력하는 정확한 순서:

1. **색상/옵션 썸네일 클릭** → 해당 옵션이 선택되고, 하단에 SKU가 표시됨
2. **체크박스 클릭** → 해당 옵션이 발주 목록에 등록됨 (체크 안 하면 장바구니에 안 담김!)
3. **수량 필드 triple-click** → 기존 값(0) 전체 선택
4. **수량 입력** → 원하는 수량 타이핑
5. **다음 옵션 썸네일 클릭** → 2~4번 반복
6. 모든 옵션 입력 완료 후, **합계 확인** → 빈 곳을 한번 클릭하여 합계가 정상 갱신되는지 확인
7. **"장바구니 추가" 클릭**

주의사항:
- 체크박스를 깜빡하면 해당 옵션이 장바구니에 포함되지 않는다. 옵션 썸네일 위에 수량 배지가 뜨는지 확인한다.
- 합계가 실시간 갱신 안 될 수 있다. 다른 곳을 클릭하면 갱신된다.
- 이미지 영역을 클릭하면 팝업이 뜰 수 있다. 팝업이 뜨면 닫고 진행한다.

## 절대 금지 사항

- **삭제 버튼 절대 클릭 금지**: 장바구니, SKU, 상품 등 어떤 삭제 버튼도 누르지 않는다. 수량을 잘못 입력해도 사용자가 직접 수정한다. 삭제 버튼을 누르면 의도치 않은 데이터 손실이 발생할 수 있다.
- **발주 확정 절대 금지**: "바로주문", "주문하기" 등 발주 확정 버튼은 절대 클릭하지 않는다. 장바구니에 담기까지만 한다.
- **비밀번호 입력 금지**: 로그인 시 비밀번호는 사용자가 직접 입력한다.

## 에러 처리

- **시트 접근 불가**: "시트에 접근할 수 없습니다. 공유 설정을 확인해주세요." 안내
- **gviz 레이트리밋**: 빈 200 응답이 오면 10초 대기 후 재시도. 3회 실패시 Chrome 직접 읽기로 전환
- **CN인사이더 로그인 실패**: "로그인에 실패했습니다. ID와 비밀번호를 확인해주세요." 안내 후 재시도
- **캡챠 읽기 실패**: "텍스트변경" 버튼을 클릭하여 새 캡챠를 받고 재시도 (최대 3회)
- **상품 검색 실패**: B열 → F열 순서로 재검색, 그래도 실패시 미매칭 목록에 추가
- **옵션 매칭 실패**: SKU가 안 맞으면 해당 옵션을 스킵하고 사용자에게 수동 확인 요청
- **수량 입력 실수**: 절대 삭제하지 않는다. 사용자에게 "X 옵션 수량이 Y로 입력됐는데, 직접 수정해주세요." 안내

## 스마트 스케줄링 (월/수/금)

이 스킬은 월/수/금 스케줄로 실행되도록 설계되어 있다.

### 스마트 스킵 로직

매 실행시 전체 4개 시트를 스캔하되:

- 모든 사업자의 발주필요량이 0 이하 → "오늘은 발주할 상품이 없습니다" 안내 후 종료
- 특정 사업자만 소량 발주 필요 → 해당 사업자만 리포트에 표시
- 긴급(7일 미만) 상품이 있으면 무조건 리포트에 포함

스마트 스킵은 사용자가 판단한다. 스킬은 정보를 제공하고, 사용자가 결정한다.
